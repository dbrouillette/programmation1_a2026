# La validation de données en Python

## Objectifs

- Réutiliser le patron drapeau + `while` + `try`/`except` comme base commune à toutes les validations.
- Appliquer des recettes prêtes à adapter pour valider un entier, un nombre réel, une chaîne non vide, un intervalle et un ensemble de valeurs.
- Comprendre et utiliser le tuple et l'opérateur d'appartenance `in`.

## 1. Le patron général

Toutes les recettes de cette fiche suivent la même forme, déjà vue en [5.2 - La gestion des erreurs](5.2%20-%20La%20gestion%20des%20erreurs.md) :

```python
valide = False # variable de contrôle (drapeau)
while not valide:
    try:
        # Validation du TYPE
        variable = ...   # saisie et conversion
        # vérifications supplémentaires sur la VALEUR, si nécessaire
        if conditions_de_validite:
            valide = True
        else:
            print("Erreur : VALEUR invalide.")
    except ValueError as ve:
        print("Erreur : TYPE invalide.")
```

Le drapeau `valide` ne devient `True` que si **toutes** les vérifications réussissent. Chaque recette qui suit est une variation de ce moule.

## 2. Recette — Valider un entier

```python
valide = False
while not valide:
    try:
        age = int(input("Entrez votre âge : "))
        valide = True
    except ValueError:
        print("Ce n'est pas un nombre entier.")
```

Ici, aucun `try`/`except` n'est nécessaire : une chaîne de caractères ne provoque pas d'exception à la saisie. On valide directement sa **valeur** (vide ou non) avec un `while`.

## 5. Recette — Valider un intervalle numérique

On combine la validation du **type** (dans le `try`) et celle de la **valeur** (dans une condition à l'intérieur du `try`, une fois la conversion réussie) :

```python
valide = False
while not valide:
    try:
        note = int(input("Entrez une note (0 à 100) : ")) # ou conversion avec float()
        if 0 <= note <= 100:
            valide = True
        else:
            print("La note doit être entre 0 et 100.")
    except ValueError:
        print("Ce n'est pas un nombre entier.")
```

## 6. Recette — Valider l'appartenance à un ensemble de valeurs

Pour valider qu'une saisie fait partie d'un ensemble de choix précis (un menu, une liste de réponses acceptées), on a besoin de deux notions nouvelles.

> **Le tuple.** Un tuple est une collection **ordonnée et immuable** de valeurs, écrite entre parenthèses et séparées par des virgules, par exemple `(1, 2, 4)` ou `('c', 'h', 'i', 'e', 'n')`. Contrairement à une variable simple, qui contient une seule valeur, un tuple en regroupe plusieurs sous un seul nom.  
> **Référence** : Voir la [documentation officielle](https://docs.python.org/fr/3.14/library/stdtypes.html#tuples) du type `tuple`.
>
> **L'opérateur `in`.** Il teste si une valeur fait partie d'une collection : `valeur in collection` retourne `True` ou `False`. Sa négation s'écrit `valeur not in collection`.  
> **Référence** : Voir les [opérations de test d'appartenance](https://docs.python.org/fr/3.14/reference/expressions.html#membership-test-operations) de la documentation officielle.
>
> Une **liste** (`[1, 2, 4]`, avec des crochets) fonctionnerait exactement de la même façon avec `in`. On utilise ici un tuple parce que l'ensemble de choix valides ne change jamais pendant l'exécution du programme (les tuples sont **immuables**) — les listes, dont les éléments peuvent varier, seront vues plus tard dans le cours (les listes sont **mutables**).

### Exemple avec des entiers (menu)

```python
choix_valides = (1, 2, 3, 4)

valide = False
while not valide:
    try:
        choix = int(input("Votre choix (1 à 4) : "))
        if choix in choix_valides:
            valide = True
        else:
            print("Choix invalide.")
    except ValueError:
        print("Ce n'est pas un nombre entier.")
```

### Exemple avec des chaînes de caractères

Comme une chaîne ne provoque pas d'exception à la saisie, la recette est plus courte :

```python
reponses_valides = ("o", "n")

reponse = input("Continuer ? (o/n) : ").strip().lower()
while reponse not in reponses_valides:
    print("Réponse invalide.")
    reponse = input("Continuer ? (o/n) : ").strip().lower()
```

## En résumé

- Toutes les recettes de validation partagent le même moule : drapeau `valide`, boucle `while not valide:`, et un `try`/`except` quand une conversion peut échouer.
- Une chaîne de caractères ne nécessite pas de `try`/`except` : on valide directement sa valeur.
- Un intervalle se vérifie **après** une conversion réussie, à l'intérieur du `try`.
- Le tuple (`(1, 2, 3, 4)`) et l'opérateur `in` permettent de valider qu'une valeur appartient à un ensemble de choix précis, qu'il s'agisse d'entiers ou de chaînes.
