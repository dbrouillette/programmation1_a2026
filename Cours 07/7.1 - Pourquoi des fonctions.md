```python
valide = False
while not valide:

valide = False
while not valide:
    try:
        nb_biscuits = int(input("Nombre de biscuits : "))
        # ... et on recommence une troisième fois!
```

Ce code fonctionne, mais il pose plusieurs problèmes :

- **Il est long** : 30 lignes pour trois simples saisies.
- **Il est fragile** : pour changer un message d'erreur, il faut le modifier à trois endroits… et ne pas en oublier un.
- **Il est difficile à lire** : on ne voit plus *ce que fait* le programme, noyé dans *comment* il le fait.
- **Il est propice aux erreurs** : en copiant-collant, il est facile d'oublier de renommer une variable (`nb_cafes` au lieu de `nb_muffins`, par exemple).

## 2. La solution : une fonction

Une **fonction** est un bloc de code **nommé** qui accomplit **une tâche précise**. On l'écrit **une seule fois**, puis on l'utilise autant de fois qu'on veut, simplement en l'appelant par son nom.

Avec une fonction `lire_entier()` (que nous construirons au fil du cours), le même programme devient :

```python
QUANTITE_MAX = 20

nb_cafes = lire_entier("Nombre de cafés : ", 0, QUANTITE_MAX)
nb_muffins = lire_entier("Nombre de muffins : ", 0, QUANTITE_MAX)
nb_biscuits = lire_entier("Nombre de biscuits : ", 0, QUANTITE_MAX)
```

Trois lignes, qui se lisent presque comme du français. Toute la logique de validation est cachée dans la fonction, écrite et testée une seule fois.

Les fonctions permettent donc de :

| Avantage | Explication |
| --- | --- |
| **Réutiliser** | Le code est écrit une seule fois et réutilisé partout. |
| **Découper un problème** | Un gros programme devient un assemblage de petites tâches simples. |
| **Nommer une tâche** | `calculer_taxes(montant)` dit clairement ce qui se passe. |
| **Maintenance facile** | Une correction faite dans la fonction profite à tous les appels. |
| **Faciliter les tests** | On peut vérifier chaque fonction séparément. |

## 3. Tu utilises déjà des fonctions (!)

Depuis le premier cours, on utilise des fonctions **fournies par Python** sans savoir comment elles sont écrites. Il suffit de connaître leur **nom**, ce qu'on doit leur **donner** et ce qu'elles nous **renvoient**.

| Fonction | Ce qu'on lui donne | Ce qu'elle fait / renvoie |
| --- | --- | --- |
| `print("Bonjour")` | Une ou plusieurs valeurs | Affiche les valeurs (ne renvoie rien d'utile) |
| `input("Nom : ")` | Un message | Renvoie le texte saisi (`str`) |
| `int("12")` | Une valeur | Renvoie l'entier correspondant (`12`) |
| `len("Latté")` | Une chaîne ou une liste | Renvoie sa longueur (`5`) |
| `round(3.14159, 2)` | Un nombre et un nombre de décimales | Renvoie le nombre arrondi (`3.14`) |
| `sum([2.25, 4.50])` | Une liste de nombres | Renvoie leur somme (`6.75`) |
| `range(1, 6)` | Un début et une fin | Renvoie une suite d'entiers |
| `sorted([5, -2, 3, 1])` | Une liste | Renvoie une nouvelle liste (une copie) triée `[-2, 1, 3, 5]` |

> 💡 Les **méthodes** comme `"latté".upper()` ou `quantites.append(2)` sont aussi des fonctions : elles sont simplement rattachées à une valeur (une chaîne, une liste) et s'écrivent avec un point.

Dans ce cours, on apprend à **créer nos propres fonctions**, exactement comme celles-ci.

## 4. Vocabulaire

Ces termes reviendront tout au long du cours :

| Terme | Signification | Exemple |
| --- | --- | --- |
| **Définir** une fonction | Écrire son code, une seule fois, avec le mot-clé `def`. | `def calculer_taxes(montant):` |
| **Appeler** une fonction | Demander à Python d'exécuter son code. | `calculer_taxes(15.39)` |
| **Paramètre** | Variable qui reçoit une donnée, dans la **définition**. | `montant` |
| **Argument** | Valeur transmise lors de l'**appel**. | `15.39` |
| **Valeur de retour** | Résultat que la fonction renvoie à celui qui l'a appelée. | la TPS et la TVQ calculées |

On peut voir une fonction comme une **boîte noire** : on y fait entrer des données (les arguments), elle fait son travail, et elle en fait sortir un résultat (la valeur de retour).

```text
               ┌────────────────────┐
 15.39  ──────►│  calculer_taxes()  │──────►  (0.77, 1.54)
argument       └────────────────────┘       valeur de retour
(float)                                    (tuple de 2 float)
```

## En résumé

- Copier-coller du code le rend long, fragile et difficile à lire.
- Une **fonction** est un bloc de code nommé qui accomplit une tâche précise; on l'écrit une fois et on l'appelle autant de fois qu'on veut.
- `print()`, `input()`, `len()`, `round()` et `sum()` sont des fonctions fournies par Python.
- On **définit** une fonction avec ses **paramètres**; on l'**appelle** avec des **arguments**; elle peut **renvoyer** une valeur.
