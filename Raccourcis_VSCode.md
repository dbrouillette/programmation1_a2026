# Raccourcis VS Code

## Édition de base

| Raccourci | Signification |
| --- | --- |
| `Ctrl + X` | Coupe la ligne |
| `Ctrl + C` | Copie la ligne |
| `Alt + ↑/↓` | Déplace la ligne vers le haut ou le bas |
| `Maj + Alt + ↑/↓` | Duplique la ligne vers le haut ou le bas |
| `Ctrl + Maj + K` | Supprime la ligne |
| `Ctrl + Entrée` | Insère une ligne en-dessous |
| `Ctrl + Maj + Entrée` | Insère une ligne au-dessus |
| `Ctrl + Maj + \` | Faire correspondre les {}, () ou [] |
| `Ctrl + [ / ]` | Permet de désindenter ou indenter la ligne |
| `Home/End` | Permet d'aller au début ou à la fin de la ligne |
| `Ctrl + Home` | Permet d'aller au début du fichier |
| `Ctrl + End` | Permet d'aller à la fin du fichier |
| `Ctrl + ↑/↓` | Permet de monter/descendre par ligne |
| `Alt + PgUp/PgDn` | Permet de monter/descendre par page |
| `Ctrl + Maj + [` | Permet de fermer un bloc de code |
| `Ctrl + Maj + ]` | Permet d'afficher le bloc de code |
| `Ctrl + K Ctrl + [` | Permet de fermer les sous-blocs de code |
| `Ctrl + K Ctrl + ]` | Permet d'afficher les sous-blocs de code |
| `Ctrl + K Ctrl + 0` | Permet de fermer tous les blocs de code |
| `Ctrl + K Ctrl + J` | Permet d'afficher tous les blocs de code |
| `Ctrl + K Ctrl + C` | Permet d'ajouter une ligne en commentaire |
| `Ctrl + K Ctrl + U` | Permet de retirer la ligne en commentaire |
| `Ctrl + /` | Permet de commenter ou décommenter une ligne |
| `Maj + Alt + A` | Permet de commenter un bloc |
| `Alt + Z` | Active/Désactive le retour de ligne automatique |

## Navigation

| Raccourci | Signification |
| --- | --- |
| `Ctrl + T` | Montre tous les symboles |
| `Ctrl + G` | Accéder à la ligne/colonne |
| `Ctrl + Maj + O` | Accéder au symbole |
| `Ctrl + Maj + M` | Active/Désactive le panneau des problèmes |
| `F8` | Aller au problème suivant (erreur, avertissement, info) |
| `Maj + F8` | Aller au problème précédent (erreur, avertissement, info) |
| `Ctrl + Maj + Tab` | Ouverture du plus ancien éditeur utilisé |
| `Alt + ←/→` | Suivant ou Précédent |
| `Ctrl + M` | Active/Désactive l'utilisation de la touche tab pour déplacer |

## Sélection

| Raccourci | Signification |
| --- | --- |
| `Alt + Click` | Insère le curseur |
| `Ctrl + Alt + ↑/↓` | Insère le curseur au-dessus ou en-dessous |
| `Ctrl + U` | Annulation du curseur |
| `Maj + Alt + I` | Insère le curseur à la fin de chaque ligne sélectionnée |
| `Ctrl + L` | Sélectionne la ligne actuelle |
| `Ctrl + Maj + L` | Sélectionne toutes les correspondances de la sélection actuelle |
| `Ctrl + F2` | Sélectionne toutes les correspondances du mot actuel |
| `Maj + Alt + →` | Étend la sélection |
| `Maj + Alt + ←` | Réduit la sélection |
| `Maj + Alt + glisser la souris` | Sélectionne une colonne |
| `Maj + Alt + Flèches` | Sélectionne une colonne |
| `Ctrl + Maj + Alt + PgUp/PgDn` | Sélectionne une colonne |

## Général

| Raccourci | Signification |
| --- | --- |
| `Ctrl + Maj + P` ou `F1` | Ouvre la palette de commandes |
| `Ctrl + P` | Atteindre le fichier... |
| `Ctrl + Maj + N` | Ouvrir une nouvelle fenêtre |
| `Ctrl + Maj + W` | Fermer la fenêtre |
| `Ctrl + ,` | Ouvre les paramètres d'utilisateur |
| `Ctrl + K Ctrl + S` | Ouvre les raccourcis clavier |

| Raccourci | Signification |
