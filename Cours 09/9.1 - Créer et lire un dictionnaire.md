# Créer et lire un dictionnaire

## Objectifs

- Comprendre ce qu'est un dictionnaire et en quoi il diffère d'une liste.
- Créer un dictionnaire et accéder à ses valeurs par leur **clé**.
- Vérifier si une clé existe avec `in`.
- Lire une valeur sans risque avec `get()` et éviter l'erreur `KeyError`.

## 1. Principe

Au cours 8, on a rangé les produits du Café Le Binaire dans des listes :

```python
produit = ["Latté", "boisson", 4.50, 25]
print(produit[2])
```

Ça fonctionne, mais que veut dire `produit[2]`? Il faut se souvenir que l'index 2 est le prix, et l'index 3, le stock. Pour s'y retrouver, on a même dû créer des constantes `COL_PRIX`, `COL_STOCK`…

Un **dictionnaire** règle ce problème. Au lieu de ranger les valeurs par **position**, il les range par **nom** : chaque valeur est associée à une **clé**.

```python
produit = {"nom": "Latté", "categorie": "boisson", "prix": 4.50, "stock": 25}
print(produit["prix"])
```

```text
4.5
```

<p align="right"><sub><a href="https://pythontutor.com/visualize.html#code=produit%20%3D%20%7B%22nom%22%3A%20%22Latt%C3%A9%22%2C%20%22categorie%22%3A%20%22boisson%22%2C%20%22prix%22%3A%204.50%2C%20%22stock%22%3A%2025%7D%0Aprint%28produit%5B%22prix%22%5D%29&cumulative=false&heapPrimitives=nevernest&mode=display&origin=opt-frontend.js&py=311&rawInputLstJSON=%5B%5D&textReferences=false">Exécution...</a></sub></p>

Le code se lit tout seul : `produit["prix"]` est le prix du produit.

> 💡 Le nom vient du dictionnaire papier : on cherche un **mot** (la clé) pour trouver sa **définition** (la valeur). On ne cherche jamais « le 4 512e mot du dictionnaire ».

## 2. Créer un dictionnaire

Un dictionnaire s'écrit entre **accolades** `{ }`. Il contient des paires `clé: valeur`, séparées par des virgules :

```python
capitales = {"Québec": "Québec", "Ontario": "Toronto", "Manitoba": "Winnipeg"}
```

Quand il y a plusieurs paires, on écrit souvent une paire par ligne. C'est plus lisible, et la virgule après la dernière paire est permise en Python :

```python
produit = {
    "nom": "Latté",
    "categorie": "boisson",
    "prix": 4.50,
    "stock": 25,
    "disponible": True,
}
```

Un dictionnaire **vide** s'écrit `{}`. On le remplira plus tard :

```python
inventaire = {}
```

### Les clés et les valeurs

| | Clés | Valeurs |
| --- | --- | --- |
| Types permis | Le plus souvent des **chaînes**; aussi des nombres ou des tuples | **N'importe quoi** : nombres, chaînes, booléens, listes, autres dictionnaires… |
| Doublons | ❌ Chaque clé est **unique** | ✅ Deux clés peuvent avoir la même valeur |

```python
# Des clés entières sont permises : ici, le numéro de local
locaux = {1234: "Labo de programmation", 2050: "Salle de classe"}

# Une valeur peut être une liste
notes = {"Marie": [87, 92, 78], "Luc": [62, 70]}
```

> ⚠️ Une **liste** ne peut pas servir de clé : `{[1, 2]: "a"}` provoque `TypeError: unhashable type: 'list'`. Les clés doivent être des valeurs qui ne changent pas, comme les chaînes, les nombres et les tuples.

Si on répète une clé à la création, seule la **dernière** valeur est conservée :

```python
couleurs = {"rouge": 1, "vert": 2, "rouge": 3}
print(couleurs)
```

```text
{'rouge': 3, 'vert': 2}
```

## 3. Lire une valeur

On accède à une valeur avec la clé entre **crochets**, comme un index de liste :

```python
produit = {"nom": "Latté", "prix": 4.50, "stock": 25}

print(produit["nom"])
print(f"{produit['nom']} : {produit['prix']:.2f} $")
total = produit["prix"] * 2
print(total)
```

```text
Latté
Latté : 4.50 $
9.0
```

> ⚠️ Dans une f-string délimitée par `"…"`, la clé s'écrit avec des guillemets **simples** : `f"{produit['nom']}"`. Utiliser les mêmes guillemets que la f-string est une erreur de syntaxe dans les anciennes versions de Python.

### L'erreur `KeyError`

Lire une clé qui **n'existe pas** provoque une erreur :

```python
produit = {"nom": "Latté", "prix": 4.50, "stock": 25}
print(produit["taille"])
```

```text
KeyError: 'taille'
```

<p align="right"><sub><a href="https://pythontutor.com/visualize.html#code=produit%20%3D%20%7B%22nom%22%3A%20%22Latt%C3%A9%22%2C%20%22prix%22%3A%204.50%2C%20%22stock%22%3A%2025%7D%0Aprint%28produit%5B%22taille%22%5D%29&cumulative=false&heapPrimitives=nevernest&mode=display&origin=opt-frontend.js&py=311&rawInputLstJSON=%5B%5D&textReferences=false">Exécution...</a></sub></p>

Les clés sont aussi sensibles aux **majuscules** et aux **accents** : `produit["Prix"]` et `produit["prix"]` sont deux clés différentes.

> 💡 Un dictionnaire n'a **pas d'index** : `produit[0]` ne donne pas la première valeur. Python cherche une clé qui vaudrait `0`, et lève une `KeyError`.

## 4. Vérifier si une clé existe : `in`

L'opérateur `in`, vu avec les listes, vérifie si une **clé** existe :

```python
produit = {"nom": "Latté", "prix": 4.50, "stock": 25}

print("prix" in produit)        # True
print("taille" in produit)      # False
print(4.50 in produit)          # False : in cherche dans les clés, pas dans les valeurs!

if "taille" in produit:
    print(f"Taille : {produit['taille']}")
else:
    print("Taille non précisée.")
```

```text
True
False
False
Taille non précisée.
```

## 5. Lire sans risque : `get()`

La méthode `get(cle, defaut)` renvoie la valeur associée à la clé si elle existe, sinon la **valeur par défaut**. Elle ne lève jamais de `KeyError`.

```python
produit = {"nom": "Latté", "prix": 4.50, "stock": 25}

print(produit.get("prix", 0))              # 4.5 : la clé existe
print(produit.get("taille", "moyen"))      # moyen : la clé n'existe pas
print(produit.get("taille"))               # None : aucune valeur par défaut fournie
```

```text
4.5
moyen
None
```

<p align="right"><sub><a href="https://pythontutor.com/visualize.html#code=produit%20%3D%20%7B%22nom%22%3A%20%22Latt%C3%A9%22%2C%20%22prix%22%3A%204.50%2C%20%22stock%22%3A%2025%7D%0A%0Aprint%28produit.get%28%22prix%22%2C%200%29%29%20%20%20%20%20%20%20%20%20%20%20%20%20%20%23%204.5%20%3A%20la%20cl%C3%A9%20existe%0Aprint%28produit.get%28%22taille%22%2C%20%22moyen%22%29%29%20%20%20%20%20%20%23%20moyen%20%3A%20la%20cl%C3%A9%20n%27existe%20pas%0Aprint%28produit.get%28%22taille%22%29%29%20%20%20%20%20%20%20%20%20%20%20%20%20%20%20%23%20None%20%3A%20aucune%20valeur%20par%20d%C3%A9faut%20fournie&cumulative=false&heapPrimitives=nevernest&mode=display&origin=opt-frontend.js&py=311&rawInputLstJSON=%5B%5D&textReferences=false">Exécution...</a></sub></p>

> 📌 **Règle pratique** : on utilise `d[cle]` quand la clé **doit** exister (une absence serait un bogue), et `d.get(cle, defaut)` quand elle **peut** être absente.

## En résumé

- Un dictionnaire associe des **clés** (uniques) à des **valeurs** : `d = {"nom": "Latté", "prix": 4.50}`.
- Il s'écrit entre accolades; un dictionnaire vide s'écrit `{}`.
- `d[cle]` lit une valeur; une clé absente provoque une `KeyError`.
- `cle in d` vérifie si une clé existe (on cherche dans les clés, pas dans les valeurs).
- `d.get(cle, defaut)` lit une valeur sans risque d'erreur.
