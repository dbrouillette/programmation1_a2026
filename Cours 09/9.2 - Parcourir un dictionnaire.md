# Parcourir un dictionnaire

## Objectifs

- Parcourir les clés d'un dictionnaire avec une boucle `for`.
- Utiliser `keys()`, `values()` et `items()`.
- Calculer un total, un maximum ou une moyenne à partir des valeurs.
- Compter des occurrences avec le **patron compteur**.
- Construire un dictionnaire à partir d'une liste.

> 🎄 **Fil conducteur** : les exemples de cette fiche préparent le TP3, le spectacle de Noël. Une chanson y est une suite de notes (`"DO4"`, `"MI4"`, `"SOL4"`…), et chaque note doit être traduite en **fréquence** (pour le son) et en **couleur** (pour les lumières du sapin). Ce sont deux associations parfaites pour des dictionnaires!

## 1. Parcourir les clés

Une boucle `for` sur un dictionnaire donne ses **clés**, une à une, dans l'ordre d'ajout :

```python
FREQUENCES = {
    "DO4": 262,
    "RE4": 294,
    "MI4": 330,
    "FA4": 349,
    "SOL4": 392,
    "LA4": 440,
    "SI4": 494,
    "DO5": 523,
}

for note in FREQUENCES:
    print(f"{note:<5}{FREQUENCES[note]:>4} Hz")
```

```text
DO4   262 Hz
RE4   294 Hz
MI4   330 Hz
FA4   349 Hz
SOL4  392 Hz
LA4   440 Hz
SI4   494 Hz
DO5   523 Hz
```

> 💡 Ce sont les fréquences réelles des notes de la gamme, arrondies à l'entier. Le `LA4` à 440 Hz est la note de référence qu'utilisent les musiciens pour s'accorder.

## 2. `keys()`, `values()` et `items()`

Trois méthodes donnent accès aux différentes parties d'un dictionnaire :

| Méthode | Donne… | Exemple de boucle |
| --- | --- | --- |
| `d.keys()` | les clés | `for note in FREQUENCES.keys():` |
| `d.values()` | les valeurs | `for frequence in FREQUENCES.values():` |
| `d.items()` | les **paires** (clé, valeur), sous forme de tuples | `for note, frequence in FREQUENCES.items():` |

`for cle in d.keys():` est équivalent à `for cle in d:`. On utilise souvent la version courte.

### `items()` : la clé et la valeur en même temps

`items()` donne des tuples `(clé, valeur)`, qu'on **déballe** directement dans deux variables, comme les tuples renvoyés par une fonction en [7.4](../Cours%2007/7.4%20-%20Renvoyer%20une%20valeur.md) :

```python
FREQUENCES = {"DO4": 262, "RE4": 294, "MI4": 330}

for note, frequence in FREQUENCES.items():
    print(f"{note} → {frequence} Hz")
```

```text
DO4 → 262 Hz
RE4 → 294 Hz
MI4 → 330 Hz
```

<p align="right"><sub><a href="https://pythontutor.com/visualize.html#code=FREQUENCES%20%3D%20%7B%22DO4%22%3A%20262%2C%20%22RE4%22%3A%20294%2C%20%22MI4%22%3A%20330%7D%0A%0Afor%20note%2C%20frequence%20in%20FREQUENCES.items%28%29%3A%0A%20%20%20%20print%28f%22%7Bnote%7D%20%E2%86%92%20%7Bfrequence%7D%20Hz%22%29&cumulative=false&heapPrimitives=nevernest&mode=display&origin=opt-frontend.js&py=311&rawInputLstJSON=%5B%5D&textReferences=false">Exécution...</a></sub></p>

> 📌 **Règle pratique** : quand la boucle a besoin de la clé **et** de la valeur, on utilise `items()`. C'est plus lisible que `FREQUENCES[note]` répété partout.

### `values()` : calculer sur les valeurs

```python
duree_par_note = {"DO4": 900, "MI4": 2700, "SOL4": 600}

total = 0
for duree in duree_par_note.values():
    total += duree
print(f"Durée totale : {total} ms")

print(sum(duree_par_note.values()))     # sum() fonctionne aussi
```

```text
Durée totale : 4200 ms
4200
```

<p align="right"><sub><a href="https://pythontutor.com/visualize.html#code=duree_par_note%20%3D%20%7B%22DO4%22%3A%20900%2C%20%22MI4%22%3A%202700%2C%20%22SOL4%22%3A%20600%7D%0A%0Atotal%20%3D%200%0Afor%20duree%20in%20duree_par_note.values%28%29%3A%0A%20%20%20%20total%20%2B%3D%20duree%0Aprint%28f%22Dur%C3%A9e%20totale%20%3A%20%7Btotal%7D%20ms%22%29%0A%0Aprint%28sum%28duree_par_note.values%28%29%29%29%20%20%20%20%20%23%20sum%28%29%20fonctionne%20aussi&cumulative=false&heapPrimitives=nevernest&mode=display&origin=opt-frontend.js&py=311&rawInputLstJSON=%5B%5D&textReferences=false">Exécution...</a></sub></p>

`sum()`, `min()`, `max()` et `len()` acceptent tous `d.values()`. Attention : `max(d.values())` donne la plus grande **valeur**, mais pas la clé qui lui correspond.

## 3. Trouver la clé de la plus grande valeur

Pour savoir **quelle note** dure le plus longtemps, il faut garder la clé en mémoire pendant le parcours. C'est la même recette que la recherche du maximum dans une liste :

```python
duree_par_note = {"DO4": 900, "MI4": 2700, "SOL4": 600}

note_max = ""
duree_max = -1
for note, duree in duree_par_note.items():
    if duree > duree_max:
        note_max = note
        duree_max = duree

print(f"Note la plus longue : {note_max} ({duree_max} ms)")
```

```text
Note la plus longue : MI4 (2700 ms)
```

## 4. Le patron compteur

C'est **l'utilisation la plus célèbre** des dictionnaires : compter combien de fois chaque valeur apparaît dans une liste.

Les premières notes de *Vive le vent* :

```python
melodie = ["MI4", "MI4", "MI4", "MI4", "MI4", "MI4", "MI4", "SOL4", "DO4", "RE4", "MI4"]

compteur = {}
for note in melodie:
    if note in compteur:
        compteur[note] += 1         # déjà vue : on augmente
    else:
        compteur[note] = 1          # première fois : on crée la clé

print(compteur)
```

```text
{'MI4': 8, 'SOL4': 1, 'DO4': 1, 'RE4': 1}
```

<p align="right"><sub><a href="https://pythontutor.com/visualize.html#code=melodie%20%3D%20%5B%22MI4%22%2C%20%22MI4%22%2C%20%22MI4%22%2C%20%22MI4%22%2C%20%22MI4%22%2C%20%22MI4%22%2C%20%22MI4%22%2C%20%22SOL4%22%2C%20%22DO4%22%2C%20%22RE4%22%2C%20%22MI4%22%5D%0A%0Acompteur%20%3D%20%7B%7D%0Afor%20note%20in%20melodie%3A%0A%20%20%20%20if%20note%20in%20compteur%3A%0A%20%20%20%20%20%20%20%20compteur%5Bnote%5D%20%2B%3D%201%20%20%20%20%20%20%20%20%20%23%20d%C3%A9j%C3%A0%20vue%20%3A%20on%20augmente%0A%20%20%20%20else%3A%0A%20%20%20%20%20%20%20%20compteur%5Bnote%5D%20%3D%201%20%20%20%20%20%20%20%20%20%20%23%20premi%C3%A8re%20fois%20%3A%20on%20cr%C3%A9e%20la%20cl%C3%A9%0A%0Aprint%28compteur%29&cumulative=false&heapPrimitives=nevernest&mode=display&origin=opt-frontend.js&py=311&rawInputLstJSON=%5B%5D&textReferences=false">Exécution...</a></sub></p>

La version courte, avec `get()` : si la note n'est pas encore dans le dictionnaire, `get()` renvoie `0`, auquel on ajoute 1.

```python
compteur = {}
for note in melodie:
    compteur[note] = compteur.get(note, 0) + 1
```

> 📌 **Le patron compteur** est à connaître par cœur : `compteur[cle] = compteur.get(cle, 0) + 1`. Il sert à compter des votes, des mots dans un texte, des notes dans une chanson, des ventes par produit…

### Additionner plutôt que compter

La même recette permet d'**additionner** une valeur par clé. Une chanson est une liste 2D `[note, intensite, duree]`; on calcule la durée totale de chaque note :

```python
chanson = [
    ["MI4", 80, 300],
    ["MI4", 80, 300],
    ["MI4", 100, 600],
    ["SOL4", 80, 300],
    ["DO4", 60, 450],
]

duree_par_note = {}
for rangee in chanson:
    note = rangee[0]
    duree = rangee[2]
    duree_par_note[note] = duree_par_note.get(note, 0) + duree

print(duree_par_note)
```

```text
{'MI4': 1200, 'SOL4': 300, 'DO4': 450}
```

## 5. Parcourir dans un ordre choisi

Un dictionnaire se parcourt dans l'**ordre d'ajout**. Pour un autre ordre, deux options :

**Parcourir une liste de référence**, et utiliser `get()` pour les clés absentes. C'est idéal pour afficher les notes dans l'ordre de la gamme, même celles qui n'apparaissent pas dans la chanson :

```python
GAMME = ["DO4", "RE4", "MI4", "FA4", "SOL4", "LA4", "SI4", "DO5"]
compteur = {"MI4": 8, "SOL4": 1, "DO4": 1, "RE4": 1}

for note in GAMME:
    print(f"{note:<5}{compteur.get(note, 0):>3}")
```

```text
DO4    1
RE4    1
MI4    8
FA4    0
SOL4   1
LA4    0
SI4    0
DO5    0
```

<p align="right"><sub><a href="https://pythontutor.com/visualize.html#code=GAMME%20%3D%20%5B%22DO4%22%2C%20%22RE4%22%2C%20%22MI4%22%2C%20%22FA4%22%2C%20%22SOL4%22%2C%20%22LA4%22%2C%20%22SI4%22%2C%20%22DO5%22%5D%0Acompteur%20%3D%20%7B%22MI4%22%3A%208%2C%20%22SOL4%22%3A%201%2C%20%22DO4%22%3A%201%2C%20%22RE4%22%3A%201%7D%0A%0Afor%20note%20in%20GAMME%3A%0A%20%20%20%20print%28f%22%7Bnote%3A%3C5%7D%7Bcompteur.get%28note%2C%200%29%3A%3E3%7D%22%29&cumulative=false&heapPrimitives=nevernest&mode=display&origin=opt-frontend.js&py=311&rawInputLstJSON=%5B%5D&textReferences=false">Exécution...</a></sub></p>

**Trier les clés** avec `sorted()`, qui renvoie une liste triée des clés :

```python
compteur = {"MI4": 8, "SOL4": 1, "DO4": 1, "RE4": 1}
for note in sorted(compteur):
    print(note, compteur[note])
```

```text
DO4 1
MI4 8
RE4 1
SOL4 1
```

> ⚠️ `sorted()` trie les chaînes par ordre **alphabétique**, pas musical : `RE4` arrive après `MI4`. D'où l'intérêt de la liste de référence `GAMME`.

## 6. Construire un dictionnaire à partir de listes

On part d'un dictionnaire vide, et on ajoute une paire à chaque tour de boucle :

```python
notes = ["DO4", "RE4", "MI4"]
frequences = [262, 294, 330]

table = {}
for i in range(len(notes)):
    table[notes[i]] = frequences[i]

print(table)
```

```text
{'DO4': 262, 'RE4': 294, 'MI4': 330}
```

<p align="right"><sub><a href="https://pythontutor.com/visualize.html#code=notes%20%3D%20%5B%22DO4%22%2C%20%22RE4%22%2C%20%22MI4%22%5D%0Afrequences%20%3D%20%5B262%2C%20294%2C%20330%5D%0A%0Atable%20%3D%20%7B%7D%0Afor%20i%20in%20range%28len%28notes%29%29%3A%0A%20%20%20%20table%5Bnotes%5Bi%5D%5D%20%3D%20frequences%5Bi%5D%0A%0Aprint%28table%29&cumulative=false&heapPrimitives=nevernest&mode=display&origin=opt-frontend.js&py=311&rawInputLstJSON=%5B%5D&textReferences=false">Exécution...</a></sub></p>

> 💡 On peut aussi **inverser** un dictionnaire (les valeurs deviennent les clés) : `inverse[valeur] = cle` dans une boucle sur `items()`. Attention : si deux clés ont la même valeur, une seule survivra dans l'inverse, puisque les clés sont uniques.

## 7. Piège : modifier pendant le parcours

On ne peut pas **ajouter ni supprimer** de clés dans un dictionnaire pendant qu'on le parcourt :

```python
# ❌ Mauvais : RuntimeError: dictionary changed size during iteration
compteur = {"MI4": 8, "FA4": 0, "SOL4": 1, "LA4": 0}
for note in compteur:
    if compteur[note] == 0:
        del compteur[note]
```

La solution : parcourir une **copie de la liste des clés**, obtenue avec `list(d)` :

```python
# ✅ Bon : on parcourt une liste indépendante du dictionnaire
compteur = {"MI4": 8, "FA4": 0, "SOL4": 1, "LA4": 0}
for note in list(compteur):
    if compteur[note] == 0:
        del compteur[note]
print(compteur)
```

```text
{'MI4': 8, 'SOL4': 1}
```

> 💡 **Modifier la valeur** d'une clé existante pendant le parcours est permis (`compteur[note] += 1`) : c'est seulement l'ajout ou la suppression de clés qui pose problème.

## En résumé

- `for cle in d:` parcourt les clés, dans l'ordre d'ajout.
- `d.values()` donne les valeurs; `d.items()` donne les paires, qu'on déballe : `for cle, valeur in d.items():`.
- `sum()`, `min()` et `max()` fonctionnent sur `d.values()`; pour retrouver la **clé** du maximum, on fait la recherche soi-même.
- **Patron compteur** : `compteur[cle] = compteur.get(cle, 0) + 1`.
- Pour un ordre précis, on parcourt une liste de référence ou `sorted(d)`.
- On ne supprime pas de clés pendant le parcours : on parcourt `list(d)` à la place.
