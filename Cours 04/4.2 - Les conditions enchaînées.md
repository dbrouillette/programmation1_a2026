# La structure `if` / `elif` / `else`

## Objectifs

- Enchaîner plusieurs conditions avec `elif`.
- Comprendre pourquoi l'ordre des conditions est important.
- Distinguer une chaîne de `elif` d'une suite de `if` indépendants.
- Connaître l'instruction `match`/`case` comme structure alternative pour les choix multiples.

Quand une seule condition (`if`/`else`) ne suffit pas — qu'il faut départager plus de deux cas — Python propose un mot-clé dédié : **`elif`** (contraction de *else if*).

## 1. Syntaxe

```python
if condition1:
    # instructions si condition1 vraie
elif condition2:
    # instructions si condition2 vraie (et condition1 fausse)
elif condition3:
    # instructions si condition3 vraie (et les précédentes fausses)
else:
    # ce bloc est optionnel, mais recommandé pour traiter les cas imprévus
```

### À retenir

- **Une seule branche est exécutée** : dès qu'une condition est vraie, Python exécute son bloc et **ignore tout le reste** de la chaîne de conditions (même si une condition plus bas serait aussi vraie).
- **L'ordre des conditions est important** — voir section 3.
- Sans `else` final, le programme ne fait **rien** si toutes les conditions sont fausses.

## 2. Exemple

Déterminer la mention associée à une note :

```python
note = 85

if note >= 90:
    print("Mention : Excellent")
elif note >= 75:
    print("Mention : Très bien")
elif note >= 60:
    print("Mention : Bien")
elif note >= 50:
    print("Mention : Passable")
else:
    print("Mention : Échec")
```

## 3. Pourquoi l'ordre des conditions compte

```python
note = 95

# Version incorrecte
if note >= 50:
    print("Passable")
elif note >= 90:
    print("Excellent")   # ⚠️ jamais atteint! note >= 50 est déjà vrai avant.
```

Ici, `note = 95` satisfait `note >= 50` en premier — la branche `Excellent` ne sera **jamais** exécutée, peu importe la note. **Règle générale : lorsque les conditions testent des plages qui se chevauchent, on les ordonne de la plus restrictive à la plus large** (ou l'inverse, selon le sens des comparaisons).

## 4. `elif` vs plusieurs `if` indépendants

```python
# Chaîne elif : une seule branche exécutée
if x > 0:
    print("Positif")
elif x > 10:
    print("Supérieur à 10")   # jamais vérifié si x > 0 est déjà vrai

# Plusieurs if indépendants : chaque condition est évaluée séparément
if x > 0:
    print("Positif")
if x > 10:
    print("Supérieur à 10")   # peut s'afficher EN PLUS du message précédent
```

Utilisez `elif` lorsque les cas sont **mutuellement exclusifs** (un seul doit s'appliquer); utilisez des `if` séparés lorsque **plusieurs messages indépendants** peuvent s'afficher pour un même jeu de valeurs.

## 5. L'instruction `match`/`case` (alternative à `elif`)

Quand on doit comparer une **même variable** à de nombreuses valeurs possibles, une longue chaîne `if`/`elif` devient parfois difficile à lire. Depuis Python 3.10, une structure est dédiée à ce genre de sélection multiple : **`match`/`case`** (l'équivalent du `switch` d'autres langages).

```python
match jour:
    case 1:
        print("Lundi")
    case 2:
        print("Mardi")
    case _:
        print("Jour invalide")
```

- La ligne `match nom_variable:` ouvre la structure, et chaque `case valeur:` propose un cas à comparer à la variable.
- Le `:` et l'indentation sont **obligatoires**, comme pour `if`.
- Le cas `_` sert de « cas par défaut » — il doit toujours être placé **en dernier**, car `match` évalue les `case` dans l'ordre et s'arrête au premier qui correspond.

### 5.1 Pas de « *fall-through* »

Dès qu'un `case` correspond et que son bloc est exécuté, Python **sort automatiquement** de la structure : il n'y a jamais de risque d'enchaîner accidentellement sur les `case` suivants.

```python
match note:
    case 10:
        print("Parfait!")
    case 9:
        print("Excellent!")
    case _:
        print("Continue tes efforts.")
```

### 5.2 Regrouper plusieurs valeurs pour un même `case`

Le symbole `|` (« ou ») permet à un seul `case` de correspondre à plusieurs valeurs à la fois :

```python
match jour:
    case 6 | 7:
        print("Fin de semaine")
    case _:
        print("Jour de semaine")
```

### 5.3 `match` fonctionne aussi avec des chaînes de caractères

`match` peut comparer directement des chaînes de caractères, pas seulement des nombres :

```python
categorie = input("Entrez une catégorie : ").strip().lower()

match categorie:
    case "natation":
        print("Bassin A")
    case "course":
        print("Piste extérieure")
    case "cyclisme":
        print("Vélodrome")
    case _:
        print("Catégorie inconnue")
```

### 5.4 `match`/`case` ou `elif`?

| Utiliser `match`/`case` quand… | Préférer `elif` quand… |
| --- | --- |
| on compare une seule variable à plusieurs valeurs précises | les conditions testent des plages ou des expressions différentes (`note >= 90`, `age < 18`, etc.) |
| il y a beaucoup de cas à comparer (plus lisible en colonne) | il y a peu de cas, ou les conditions combinent `and`/`or` |

*`match`/`case` a été introduit en Python 3.10 — s'assurer que l'environnement d'exécution est suffisamment récent avant de l'utiliser.*

## En résumé

- `elif` enchaîne des conditions supplémentaires après un `if`; une seule branche s'exécute au total.
- L'ordre des `elif` est déterminant quand les plages testées se chevauchent.
- Un `else` final (optionnel) attrape tous les cas non prévus par les conditions précédentes.
- Une chaîne `if`/`elif` n'est pas équivalente à plusieurs `if` indépendants : ces derniers sont tous évalués, peu importe le résultat des autres.
- `match`/`case` (Python 3.10+) est une alternative à `elif` quand une seule variable est comparée à plusieurs valeurs précises; comme pour `elif`, une seule branche s'exécute (jamais de fall-through) et le cas `_` sert de cas par défaut.
