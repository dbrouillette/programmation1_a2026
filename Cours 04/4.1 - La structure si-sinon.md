# La structure conditionnelle `if` (SI)

## Objectifs

- Comprendre à quoi sert une structure conditionnelle.
- Savoir écrire un `if` simple, puis un `if`/`else`.
- Comprendre le rôle de l'indentation et du `:` dans la délimitation d'un bloc.

> 📌 Cette fiche suppose que vous maîtrisez déjà les opérateurs relationnels (`==`, `!=`, `<`, `>`, `<=`, `>=`) et logiques (`and`, `or`, `not`) vus dans la fiche [Opérateurs relationnels et logiques](../Cours%2003/3.4%20-%20Op%C3%A9rateurs%20relationnels%20et%20logiques.md).

Jusqu'ici, nos programmes exécutaient toutes leurs instructions les unes après les autres, sans exception. La structure **`SI`** (`if` en Python) permet de **prendre une décision** : exécuter certaines instructions seulement lorsqu'une condition est vraie.

## 1. Structure conditionnelle simple (`if` seul)

Le bloc est exécuté **seulement si la condition est vraie**. Rien ne se passe sinon.

```python
if condition:
    # Instructions exécutées 
    # seulement si la condition 
    # est vraie
```

### À noter

- **`condition`** est une expression booléenne (`True` ou `False`) — souvent une comparaison ou une combinaison de comparaisons avec `and`/`or`/`not`.
- **Aucune parenthèse n'est requise** autour de la condition (on peut en ajouter pour la clarté d'une expression complexe).
- **Il n'y a pas d'accolades `{ }`** pour délimiter le bloc : **l'indentation seule** détermine quelles instructions en font partie. Le `:` en fin de ligne est **obligatoire**.

**Exemple :**

```python
nombre = 5

if nombre > 0:
    print("Le nombre est positif.")
```

## 2. Structure `if` / `else` (dichotomie)

Permet de **choisir entre deux chemins** : un si la condition est vraie, un autre si elle est fausse.

```python
if condition:
    # Instructions si vrai
else:
    # Instructions si faux
```

**Exemple :**

```python
nombre = int(input("Entrez un nombre : "))

if nombre % 2 == 0:
    print("Le nombre est pair.")
else:
    print("Le nombre est impair.")
```

### À savoir

- Le bloc `else` est **optionnel**.
- Un `else` ne peut pas exister sans un `if` auquel il est rattaché — sinon, c'est une erreur de syntaxe.
- `else` **n'a jamais sa propre condition** : il s'exécute chaque fois que la condition du `if` (ou de tous les `elif` — voir la fiche suivante) est fausse.

## 3. L'indentation délimite les blocs

Contrairement à des langages comme Java ou C++ qui utilisent des accolades `{ }`, Python **impose une indentation cohérente** pour indiquer quelles lignes appartiennent à un bloc.

```python
age = 16

if age >= 18:
    print("Vous êtes majeur.")
    print("Vous pouvez voter.")   # fait partie du if
print("Fin du programme.")        # ne fait PAS partie du if
```

⚠️ Une erreur d'indentation peut soit provoquer une `IndentationError`, soit — pire — faire fonctionner le programme d'une manière différente de ce qui était voulu, sans planter.

## En résumé

- `if condition:` exécute un bloc uniquement lorsque `condition` vaut `True`.
- `else` (optionnel) gère le cas où la condition est fausse — il ne prend jamais de condition lui-même.
- L'**indentation** (et non des accolades) détermine les blocs en Python; le `:` en fin de ligne est obligatoire.
- Une condition doit toujours être une expression qui s'évalue à `True` ou `False`.
