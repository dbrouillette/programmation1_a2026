# L'opérateur ternaire (expression conditionnelle)

## Objectifs

- Comprendre le fonctionnement de l'opérateur ternaire.
- Savoir le réécrire sous la forme d'un `if`/`else` classique, et vice-versa.
- Reconnaître les situations où il vaut mieux l'éviter.

L'opérateur ternaire est l'équivalent le plus direct d'un `IIF` (*inline if*) dans d'autres langages : une condition `SI` simplifiée sur une seule ligne, qui **retourne une valeur** plutôt que d'exécuter des instructions.

## 1. Syntaxe

```python
variable = valeur_si_vrai if condition else valeur_si_faux
```

⚠️ **Particularité à retenir : la valeur voulue vient en premier, avant la condition.** On écrit `vrai if condition else faux` — ça se lit presque comme une phrase en français : « X si condition sinon Y ».

Cette expression est équivalente à :

```python
if condition:
    variable = valeur_si_vrai
else:
    variable = valeur_si_faux
```

## 2. Exemples

```python
a = 10
b = 20

maximum = a if a > b else b   # maximum = 20
print(f"Le maximum est : {maximum}")
```

L'opérateur ternaire peut aussi être utilisé **directement dans un `print()`**, sans variable intermédiaire :

```python

print("Pair" if nombre % 2 == 0 else "Impair")
```

## 3. Ce qu'il ne faut PAS faire : imbriquer des ternaires

```python
# ⚠️ Fonctionne, mais illisible
note = 72
mention = "Bien" if note >= 60 else "Passable" if note >= 50 else "Échec"
```

Techniquement valide, mais **difficile à lire au premier coup d'œil** — surtout avec plus de deux niveaux. Dès qu'il y a plus de deux issues possibles, un `if`/`elif`/`else` classique (fiche 4.2) est presque toujours préférable.

## 4. Quand l'utiliser

| Utiliser l'opérateur ternaire quand… | Préférer `if`/`elif`/`else` classique quand… |
| --- | --- |
| la condition est simple | la condition est complexe |
| une seule valeur est produite | plusieurs instructions doivent s'exécuter |
| il n'y a que 2 issues possibles | il y a 3 issues ou plus (`elif`) |

## En résumé

- Syntaxe : `[valeur =] valeur_si_vrai if condition else valeur_si_faux` — la valeur vraie vient **avant** la condition.
- Utile pour affecter une variable ou produire une valeur en une seule ligne à partir d'une condition simple.
- À éviter dès que la condition se complexifie ou qu'on serait tenté d'imbriquer plusieurs ternaires : un `if`/`elif`/`else` reste plus lisible.
