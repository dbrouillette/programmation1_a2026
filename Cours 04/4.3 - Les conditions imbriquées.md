# Les conditions imbriquées (`if` dans un `if`)

## Objectifs

- Comprendre ce qu'est une structure conditionnelle imbriquée.
- Reconnaître quand l'imbrication est justifiée.
- Savoir simplifier une imbrication à l'aide d'opérateurs logiques.

Il est parfois nécessaire de vérifier une condition **à l'intérieur** d'une autre : c'est une structure **imbriquée**.

## 1. Syntaxe et exemple

```python
age = 20
permis_voiture = True

if age >= 18:
    print("Vous êtes majeur.")

    if permis_voiture:
        print("Vous pouvez conduire.")
    else:
        print("Vous ne pouvez pas conduire sans permis.")
else:
    print("Vous êtes mineur.")
```

⚠️ **Attention à l'indentation!** C'est elle qui indique à Python que `if permis_voiture:` fait partie du bloc du premier `if`. Une erreur d'indentation change littéralement le sens du programme (ou cause une erreur).

## 2. Quand utiliser des structures imbriquées

On les utilise lorsque :

- **une condition ne doit être testée que si une autre est déjà vraie** (elle « dépend » de la première);
- il faut **raffiner une décision** après un premier test général;
- l'imbrication reste **peu profonde** (2, parfois 3 niveaux).

## 3. Exemple à plusieurs niveaux

```python
age = 22
score = 85
abonnement_premium = True
a_accepte_conditions = True

if age >= 18:                          # Niveau 1
    print("Vous êtes majeur.")

    if a_accepte_conditions:           # Niveau 2
        print("Conditions acceptées.")

        if abonnement_premium:         # Niveau 3
            print("Accès premium activé.")

            if score >= 80:            # Niveau 4
                print("Vous débloquez le niveau final !")
            else:
                print("Score insuffisant pour le niveau final.")
        else:
            print("Accès limité aux niveaux gratuits.")
    else:
        print("Vous devez accepter les conditions pour jouer.")
else:
    print("Vous êtes mineur, accès interdit.")
```

## 4. Simplifier une imbrication

Une imbrication profonde nuit à la lisibilité. On peut souvent la remplacer par une **combinaison de conditions avec `and`** :

```python
# Imbriqué
if age >= 18:
    if permis_voiture:
        print("Vous pouvez conduire.")

# Équivalent, à plat
if age >= 18 and permis_voiture:
    print("Vous pouvez conduire.")
```

Les deux versions ne sont équivalentes que lorsque **le bloc `else` de la condition extérieure n'a pas besoin d'être distinct** de celui de la condition intérieure. Si chaque niveau doit afficher un message différent en cas d'échec (comme dans l'exemple de la section 1), l'imbrication reste nécessaire — ou alors, on la reformule avec des sorties anticipées (voir la fiche 4.5 sur les bonnes pratiques).

## En résumé

- Une structure imbriquée est un `if` (ou `if`/`else`) placé à l'intérieur du bloc d'un autre `if`.
- L'indentation détermine à quel niveau (donc à quelle condition parente) chaque `if` intérieur appartient.
- On imbrique quand une condition ne fait sens que si une autre est déjà vraie.
- Une imbrication qui ne fait que combiner des conditions sans messages distincts peut souvent être remplacée par `and`, ce qui est plus lisible.
