# Une liste d'objets

## Objectifs

- Ranger plusieurs objets dans une **liste**.
- Parcourir, chercher, filtrer et calculer dans une liste d'objets.
- Comprendre qu'un objet trouvé dans la liste **est** l'objet de la liste (et non une copie).
- Retirer un objet d'une liste.
- Créer une classe qui **contient** une liste d'objets.

> 📋 **Prérequis** : [10.1 - Introduction aux classes et aux objets](10.1%20-%20Introduction%20aux%20classes%20et%20aux%20objets.md) et les listes ([6.2](../Cours%2006/6.2%20-%20Les%20listes.md)).

Dans toute la fiche, on utilise la classe `Renard` de la fiche 10.1 :

```python
ENERGIE_MAX = 100


class Renard:
    """Un renard du refuge."""

    def __init__(self, nom, couleur, age):
        self.nom = nom
        self.couleur = couleur
        self.age = age
        self.energie = 50
        self.proies = []

    def chasser(self, proie):
        """Attrape une proie : +20 d'énergie, sans dépasser ENERGIE_MAX."""
        self.proies.append(proie)
        self.energie += 20
        if self.energie > ENERGIE_MAX:
            self.energie = ENERGIE_MAX

    def __str__(self):
        return f"{self.nom}, renard {self.couleur} de {self.age} ans"
```

## 1. Principe

Un seul renard, c'est bien. Mais un refuge faunique en accueille **plusieurs**! Comme au cours 9 avec les dictionnaires, on range les objets dans une **liste**.

| Cours 9 | Cours 10 |
| --- | --- |
| Une liste de dictionnaires | Une liste d'objets |
| `renards[0]["nom"]` | `renards[0].nom` |
| `for renard in renards:` puis `renard["energie"]` | `for renard in renards:` puis `renard.energie` |

Toutes les recettes sur les listes (total, filtre, recherche, maximum) fonctionnent exactement comme avant.

## 2. Créer et parcourir la liste

```python
refuge = []
refuge.append(Renard("Roux", "roux", 3))
refuge.append(Renard("Flocon", "arctique", 2))
refuge.append(Renard("Cendre", "argenté", 4))

refuge[0].chasser("mulot")
refuge[0].chasser("lièvre")
refuge[2].chasser("campagnol")

print(f"{len(refuge)} renards au refuge")
for renard in refuge:
    print(f"{renard} : énergie {renard.energie}, {len(renard.proies)} proie(s)")
```

```text
3 renards au refuge
Roux, renard roux de 3 ans : énergie 90, 2 proie(s)
Flocon, renard arctique de 2 ans : énergie 50, 0 proie(s)
Cendre, renard argenté de 4 ans : énergie 70, 1 proie(s)
```

- `refuge[0]` est un objet `Renard` : on peut donc appeler ses méthodes directement, `refuge[0].chasser("mulot")`.
- Dans `for renard in refuge:`, la variable `renard` est, à chaque tour, **un objet** de la liste.
- On peut créer l'objet directement dans le `append()`, sans variable intermédiaire.

## 3. Chercher un objet : renvoyer l'objet, ou `None`

Pour chercher un renard par son nom, on écrit une fonction qui **renvoie l'objet trouvé**. S'il n'existe pas, elle renvoie la valeur spéciale **`None`** (« rien »).

```python
def chercher_renard(renards, nom):
    """Renvoie le renard qui porte ce nom, ou None s'il n'existe pas."""
    for renard in renards:
        if renard.nom == nom:
            return renard
    return None


trouve = chercher_renard(refuge, "Flocon")
if trouve is None:
    print("Aucun renard de ce nom.")
else:
    print(f"Trouvé : {trouve}")

print(chercher_renard(refuge, "Goupil"))
```

```text
Trouvé : Flocon, renard arctique de 2 ans
None
```

> 💡 Au cours 9, une recherche renvoyait souvent un **index** (ou `-1`). Avec des objets, on renvoie plus souvent **l'objet lui-même** (ou `None`) : le programme peut s'en servir tout de suite. On teste `None` avec `is None` ou `is not None`.

## 4. L'objet trouvé **est** l'objet de la liste

La liste ne contient pas des copies des renards, mais des **références** vers eux (comme les alias de listes vus au cours 7). L'objet renvoyé par `chercher_renard()` est donc **le même** que celui de la liste : le modifier modifie la liste.

```python
flocon = chercher_renard(refuge, "Flocon")
flocon.chasser("lemming")
flocon.age = 3

print(refuge[1])
print(refuge[1].proies, refuge[1].energie)
```

```text
Flocon, renard arctique de 3 ans
['lemming'] 70
```

C'est très pratique : on cherche un objet, on le modifie, et c'est fait. Il n'y a rien à « remettre » dans la liste.

> ⚠️ Le revers de la médaille : `copie = refuge` ne copie pas la liste (voir le cours 7). Et même `refuge.copy()` crée une nouvelle liste qui contient **les mêmes** renards!

## 5. Filtrer et calculer

```python
# Filtre : les renards en pleine forme (80 d'énergie ou plus)
en_forme = []
for renard in refuge:
    if renard.energie >= 80:
        en_forme.append(renard)
print(f"{len(en_forme)} renard(s) en pleine forme")

# Maximum : le premier renard qui a attrapé le plus de proies
meilleur = refuge[0]
for renard in refuge:
    if len(renard.proies) > len(meilleur.proies):
        meilleur = renard
print(f"Meilleur chasseur : {meilleur.nom} ({len(meilleur.proies)} proies)")

# Moyenne
total = 0
for renard in refuge:
    total += renard.energie
print(f"Énergie moyenne : {total / len(refuge):.1f}")
```

```text
1 renard(s) en pleine forme
Meilleur chasseur : Roux (2 proies)
Énergie moyenne : 76.7
```

> ⚠️ La moyenne divise par `len(refuge)` : il faut s'assurer que la liste n'est pas vide, sinon c'est une `ZeroDivisionError`.

## 6. Retirer un objet

Deux façons, selon ce qu'on a en main :

```python
# On connaît l'objet : remove()
cendre = chercher_renard(refuge, "Cendre")
if cendre is not None:
    refuge.remove(cendre)
    print(f"{cendre.nom} est relâché en forêt.")

# On connaît la position : pop()
retire = refuge.pop(0)
print(f"{retire.nom} est relâché en forêt.")

for renard in refuge:
    print(renard)
```

```text
Cendre est relâché en forêt.
Roux est relâché en forêt.
Flocon, renard arctique de 3 ans
```

> ⚠️ `remove()` lève une `ValueError` si l'objet n'est pas dans la liste : on vérifie d'abord le résultat de la recherche.

## 7. Une classe qui contient une liste d'objets

On peut aller plus loin : le **refuge** est lui-même un objet! Il a un nom, et il **contient** une liste de renards. Les fonctions des sections précédentes deviennent ses méthodes.

```python
class Refuge:
    """Un refuge faunique et ses renards."""

    def __init__(self, nom):
        self.nom = nom
        self.renards = []             # une liste d'objets Renard

    def chercher(self, nom):
        """Renvoie le renard qui porte ce nom, ou None."""
        for renard in self.renards:
            if renard.nom == nom:
                return renard
        return None

    def accueillir(self, renard):
        """Ajoute le renard, sauf si son nom existe déjà. Renvoie True si ajouté."""
        if self.chercher(renard.nom) is not None:
            return False
        self.renards.append(renard)
        return True

    def energie_moyenne(self):
        """Renvoie l'énergie moyenne des renards, ou 0 si le refuge est vide."""
        if len(self.renards) == 0:
            return 0
        total = 0
        for renard in self.renards:
            total += renard.energie
        return total / len(self.renards)


refuge = Refuge("Refuge du Lac-Saint-Pierre")
refuge.accueillir(Renard("Roux", "roux", 3))
refuge.accueillir(Renard("Flocon", "arctique", 2))
accueilli = refuge.accueillir(Renard("Roux", "argenté", 5))

refuge.chercher("Flocon").chasser("lemming")

print(f"Deuxième Roux accueilli? {accueilli}")
print(f"{refuge.nom} : {len(refuge.renards)} renards, énergie moyenne {refuge.energie_moyenne():.1f}")
```

```text
Deuxième Roux accueilli? False
Refuge du Lac-Saint-Pierre : 2 renards, énergie moyenne 60.0
```

- `self.renards` est une **liste d'objets** rangée dans un objet : les structures s'imbriquent, comme au cours 9.
- Une méthode peut appeler une autre méthode du même objet : `self.chercher(...)` dans `accueillir()`.
- `refuge.chercher("Flocon").chasser("lemming")` enchaîne les appels : on cherche le renard, puis on appelle sa méthode. Attention : si le nom n'existe pas, `chercher()` renvoie `None`, et `None.chasser("lemming")` provoque une `AttributeError`.

> 📌 Chaque classe s'occupe de **ses** données : `Renard` gère son énergie et ses proies, `Refuge` gère sa liste de renards.

## 8. Bonnes pratiques

- ✅ Choisir un **identifiant unique** (ici, le nom du renard) pour retrouver un objet, et refuser les doublons.
- ✅ Faire renvoyer l'**objet** (ou `None`) par les fonctions de recherche, et toujours tester `None` avant de s'en servir.
- ✅ Garder les calculs propres à un objet **dans sa classe**, plutôt que de les répéter partout dans le programme.
- ❌ Ne pas modifier une liste (`remove()`, `pop()`) pendant qu'on la parcourt avec `for` : des éléments seraient sautés. On cherche d'abord, on retire ensuite.

## En résumé

- Une liste peut contenir des objets : `refuge[0].nom`, `for renard in refuge:`.
- Les recettes sur les listes (filtre, maximum, total) fonctionnent : on utilise les attributs et les méthodes de chaque objet.
- Une fonction de recherche renvoie l'objet trouvé ou `None`; on teste avec `is None`.
- La liste contient des **références** : modifier un objet trouvé modifie celui de la liste.
- `liste.remove(objet)` ou `liste.pop(index)` retire un objet.
- Une classe peut contenir une liste d'objets (`Refuge.renards`) et offrir des méthodes pour la gérer.
