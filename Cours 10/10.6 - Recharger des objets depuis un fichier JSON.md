# Recharger des objets depuis un fichier JSON

## Objectifs

- Recréer des objets à partir des dictionnaires lus dans un fichier JSON.
- Valider les données lues avant de reconstruire les objets.
- Assembler le tout dans un programme qui conserve ses données d'une exécution à l'autre.

> 📋 **Prérequis** : [10.5 - Sauvegarder des objets en JSON](10.5%20-%20Sauvegarder%20des%20objets%20en%20JSON.md). On reprend sa classe `Etudiant` (avec `vers_dict()`), sa constante `CHEMIN_ETUDIANTS` et sa fonction `sauvegarder_etudiants()`.

## 1. D'un dictionnaire à un objet : `etudiant_depuis_dict()`

À la relecture, `json.load()` renvoie une liste de **dictionnaires**. Pour chacun, on recrée un objet `Etudiant` avec le constructeur, puis on lui redonne ses notes :

```python
def etudiant_depuis_dict(donnees):
    """Crée un objet Etudiant à partir d'un dictionnaire lu dans le fichier JSON."""
    etudiant = Etudiant(donnees["da"], donnees["prenom"], donnees["nom"])
    for note in donnees["notes"]:
        etudiant.ajouter_note(note)
    return etudiant

copie = etudiant_depuis_dict({"da": "2567890", "prenom": "Zoé", "nom": "Roy", "notes": [78, 90]})
print(copie)
print(f"Moyenne : {copie.moyenne():.1f}")
```

```text
2567890 - Zoé Roy
Moyenne : 84.0
```

On repasse par `ajouter_note()` plutôt que d'écrire `etudiant.notes = donnees["notes"]` : ainsi, une note invalide écrite à la main dans le fichier (`150`) est refusée, comme si elle avait été saisie au clavier.

## 2. Recharger la liste, avec validation

Le fichier peut être **absent** (première exécution), **invalide** (erreur de syntaxe JSON) ou **modifié à la main** (une clé oubliée, un DA écrit comme un nombre…). Comme au cours 9, on gère chaque cas, et on ne reconstruit que les étudiants valides :

```python
CLES_ETUDIANT = ["da", "prenom", "nom", "notes"]

def etudiant_valide(donnees):
    """Renvoie True si le dictionnaire a la forme attendue pour un étudiant."""
    if type(donnees) != dict:
        return False
    for cle in CLES_ETUDIANT:
        if cle not in donnees:
            return False
    if type(donnees["da"]) != str or type(donnees["prenom"]) != str or type(donnees["nom"]) != str:
        return False
    if type(donnees["notes"]) != list:
        return False
    for note in donnees["notes"]:
        if type(note) != int:
            return False
    return True

def charger_etudiants(chemin):
    """Renvoie la liste des étudiants du fichier JSON (liste vide en cas de problème)."""
    try:
        with open(chemin, "r", encoding="utf-8") as fichier:
            donnees = json.load(fichier)
    except FileNotFoundError:
        return []                      # première exécution : aucun étudiant
    except json.JSONDecodeError:
        print(f"Avertissement : {chemin.name} est invalide. Groupe vide.")
        return []
    if type(donnees) != list:
        print(f"Avertissement : {chemin.name} ne contient pas une liste. Groupe vide.")
        return []

    etudiants = []
    for i in range(len(donnees)):
        if etudiant_valide(donnees[i]):
            etudiants.append(etudiant_depuis_dict(donnees[i]))
        else:
            print(f"Avertissement : l'étudiant no {i + 1} est invalide et a été ignoré.")
    return etudiants

groupe = charger_etudiants(CHEMIN_ETUDIANTS)
print(f"{len(groupe)} étudiant(s) rechargé(s) :")
for etudiant in groupe:
    print(f"  {etudiant}  moyenne {etudiant.moyenne():.1f}")
```

```text
2 étudiant(s) rechargé(s) :
  2345678 - Abby Tremblay  moyenne 88.5
  2456789 - Éloi Gagnon  moyenne 64.0
```

Les étudiants rechargés sont de **vrais objets** : on peut appeler leurs méthodes (`moyenne()`, `ajouter_note()`) comme s'ils n'avaient jamais quitté la mémoire.

Si quelqu'un écrit le DA d'un étudiant comme un nombre dans le fichier (`"da": 2456789`), ce seul étudiant est ignoré :

```text
Avertissement : l'étudiant no 2 est invalide et a été ignoré.
1 étudiant(s) rechargé(s) :
  2345678 - Abby Tremblay  moyenne 88.5
```

## 3. Le programme complet : charger, travailler, sauvegarder

On retrouve le patron du cours 8 : on **charge** au démarrage, on **travaille** avec les objets en mémoire, et on **sauvegarde** après chaque modification.

```python
def main():
    groupe = charger_etudiants(CHEMIN_ETUDIANTS)
    print(f"{len(groupe)} étudiant(s) chargé(s).")

    choix = -1
    while choix != 0:
        print("\n1. Afficher  2. Ajouter un étudiant  3. Ajouter une note  4. Retirer  0. Quitter")
        choix = lire_entier("Votre choix : ", 0, 4)
        if choix == 1:
            afficher_groupe(groupe)
        elif choix == 2:
            ajouter_etudiant(groupe)
            sauvegarder_etudiants(CHEMIN_ETUDIANTS, groupe)
        elif choix == 3:
            ajouter_note(groupe)
            sauvegarder_etudiants(CHEMIN_ETUDIANTS, groupe)
        elif choix == 4:
            retirer_etudiant(groupe)
            sauvegarder_etudiants(CHEMIN_ETUDIANTS, groupe)
```

## 4. Bonnes pratiques

- ✅ Une méthode `vers_dict()` dans la classe, et une fonction `..._depuis_dict()` pour le chemin inverse : toute la traduction est à un seul endroit.
- ✅ Sauvegarder seulement les **données de base** (DA, nom, notes), jamais les valeurs calculées (moyenne).
- ✅ Recréer les objets avec le **constructeur** et les **méthodes** de la classe : leurs validations s'appliquent aussi aux données lues.
- ✅ Valider la forme des données lues : un fichier JSON peut avoir été modifié à la main.
- ✅ Sauvegarder **après chaque modification** : un programme fermé brusquement ne perd rien.

## En résumé

- À la relecture, `json.load()` renvoie des dictionnaires, que `etudiant_depuis_dict()` retransforme en objets.
- On recrée les objets avec le **constructeur** et les **méthodes** de la classe : leurs validations s'appliquent aussi aux données lues.
- On valide chaque dictionnaire avant de le reconstruire, et on gère `FileNotFoundError` et `json.JSONDecodeError`.
- Patron : charger au démarrage, travailler avec les objets, sauvegarder après chaque modification.
