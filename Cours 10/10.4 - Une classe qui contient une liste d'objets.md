# Une classe qui contient une liste d'objets

## Objectifs

- Créer une classe dont un attribut est une **liste d'objets**.
- Transformer les fonctions sur une liste d'objets en **méthodes**.
- Faire collaborer deux classes : chacune s'occupe de ses propres données.

> 📋 **Prérequis** : [10.3 - Une liste d'objets](10.3%20-%20Une%20liste%20d'objets.md).

> 🦊 **Fil conducteur** : dans les fiches 10.1 à 10.4, on programme les renards d'un refuge faunique.

Dans toute la fiche, on utilise la classe `Renard` des fiches 10.1 et 10.2 :

```python
ENERGIE_MAX = 100

class Renard:
    """Un renard du refuge."""

    def __init__(self, nom, couleur, age):
        self.nom = nom
        self.couleur = couleur
        self.age = age
        self.energie = 50
        self.proies = []

    def chasser(self, proie):
        """Attrape une proie : +20 d'énergie, sans dépasser ENERGIE_MAX."""
        self.proies.append(proie)
        self.energie += 20
        if self.energie > ENERGIE_MAX:
            self.energie = ENERGIE_MAX

    def __str__(self):
        return f"{self.nom}, renard {self.couleur} de {self.age} ans"
```

## 1. Une classe qui contient une liste d'objets

On peut aller plus loin : le **refuge** est lui-même un objet! Il a un nom, et il **contient** une liste de renards. Les fonctions des sections précédentes deviennent ses méthodes.

```python
class Refuge:
    """Un refuge faunique et ses renards."""

    def __init__(self, nom):
        self.nom = nom
        self.renards = []             # une liste d'objets Renard

    def chercher(self, nom):
        """Renvoie le renard qui porte ce nom, ou None."""
        for renard in self.renards:
            if renard.nom == nom:
                return renard
        return None

    def accueillir(self, renard):
        """Ajoute le renard, sauf si son nom existe déjà. Renvoie True si ajouté."""
        if self.chercher(renard.nom) is not None:
            return False
        self.renards.append(renard)
        return True

    def energie_moyenne(self):
        """Renvoie l'énergie moyenne des renards, ou 0 si le refuge est vide."""
        if len(self.renards) == 0:
            return 0
        total = 0
        for renard in self.renards:
            total += renard.energie
        return total / len(self.renards)

refuge = Refuge("Refuge du Lac-Saint-Pierre")
refuge.accueillir(Renard("Roux", "roux", 3))
refuge.accueillir(Renard("Flocon", "arctique", 2))
accueilli = refuge.accueillir(Renard("Roux", "argenté", 5))

refuge.chercher("Flocon").chasser("lemming")

print(f"Deuxième Roux accueilli? {accueilli}")
print(f"{refuge.nom} : {len(refuge.renards)} renards, énergie moyenne {refuge.energie_moyenne():.1f}")
```

```text
Deuxième Roux accueilli? False
Refuge du Lac-Saint-Pierre : 2 renards, énergie moyenne 60.0
```

- `self.renards` est une **liste d'objets** rangée dans un objet : les structures s'imbriquent, comme au cours 9.
- Une méthode peut appeler une autre méthode du même objet : `self.chercher(...)` dans `accueillir()`.
- `refuge.chercher("Flocon").chasser("lemming")` enchaîne les appels : on cherche le renard, puis on appelle sa méthode. Attention : si le nom n'existe pas, `chercher()` renvoie `None`, et `None.chasser("lemming")` provoque une `AttributeError`.

> 📌 Chaque classe s'occupe de **ses** données : `Renard` gère son énergie et ses proies, `Refuge` gère sa liste de renards.

## En résumé

- Une classe peut contenir une liste d'objets : `Refuge.renards`.
- Les fonctions de recherche et de calcul deviennent des méthodes de cette classe.
- Une méthode peut appeler une autre méthode du même objet : `self.chercher(...)`.
- Chaque classe s'occupe de **ses** données : le renard gère son énergie, le refuge gère sa liste.
