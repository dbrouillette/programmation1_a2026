# Sauvegarder et recharger des objets en CSV

## Objectifs

- Représenter une liste d'objets dans un fichier CSV : **une ligne par objet**, une colonne par attribut.
- Convertir un objet en ligne CSV avec une méthode `vers_ligne_csv()`.
- Recréer un objet à partir d'une ligne CSV, en validant les champs lus.
- Changer le format de sauvegarde d'un programme sans toucher au reste du code.

> 📋 **Prérequis** : [10.6 - Recharger des objets depuis un fichier JSON](10.6%20-%20Recharger%20des%20objets%20depuis%20un%20fichier%20JSON.md) et [8.6 - Les fichiers CSV à la main](../Cours%2008/8.6%20-%20Les%20fichiers%20CSV%20à%20la%20main.md).

> 🎓 On reprend la liste des étudiants des fiches 10.5 et 10.6.

## 1. Pourquoi le CSV?

En JSON, la liste des étudiants se relit en une ligne de code, avec ses types. Mais on veut parfois **ouvrir les données dans Excel** : remettre les notes à la direction, faire un graphique, imprimer une liste. C'est le rôle du CSV (fiche 8.6).

Le principe est simple : **une ligne par objet**, **une colonne par attribut**.

```text
da,prenom,nom,notes
2345678,Abby,Tremblay,85 92
2456789,Éloi,Gagnon,64
2567890,Zoé,Roy,
```

Une difficulté : `notes` est une **liste**, mais une case de tableau ne contient qu'un texte. On range donc toutes les notes dans la même colonne, **séparées par des espaces** (`85 92`). Une case vide veut dire : aucune note.

> 💡 Pourquoi des espaces, et non des virgules ou des points-virgules? La virgule sépare déjà les colonnes, et Excel en français utilise le point-virgule (fiche 8.6). L'espace ne gêne personne, et `split()` sans argument découpe justement sur les espaces.

## 2. D'un objet à une ligne : `vers_ligne_csv()`

Comme `vers_dict()` pour le JSON, on ajoute à la classe une méthode qui **traduit** l'objet. Elle renvoie la ligne CSV de l'étudiant, sans le `\n` :

```python
class Etudiant:
    """Un étudiant du groupe-cours."""

    def __init__(self, da, prenom, nom):
        self.da = da
        self.prenom = prenom
        self.nom = nom
        self.notes = []

    def ajouter_note(self, note):
        """Ajoute une note, si elle est entre 0 et 100."""
        if 0 <= note <= 100:
            self.notes.append(note)

    def moyenne(self):
        """Renvoie la moyenne des notes, ou 0 s'il n'y en a aucune."""
        if len(self.notes) == 0:
            return 0
        return sum(self.notes) / len(self.notes)

    def vers_ligne_csv(self):
        """Renvoie la ligne CSV de l'étudiant : da,prenom,nom,notes (notes séparées par des espaces)."""
        textes_notes = []
        for note in self.notes:
            textes_notes.append(str(note))
        notes = " ".join(textes_notes)
        return f"{self.da},{self.prenom},{self.nom},{notes}"

    def __str__(self):
        return f"{self.da} - {self.prenom} {self.nom}"


abby = Etudiant("2345678", "Abby", "Tremblay")
abby.ajouter_note(85)
abby.ajouter_note(92)
print(abby.vers_ligne_csv())

zoe = Etudiant("2567890", "Zoé", "Roy")
print(zoe.vers_ligne_csv())
```

```text
2345678,Abby,Tremblay,85 92
2567890,Zoé,Roy,
```

## 3. Sauvegarder la liste

On écrit l'**en-tête**, puis une ligne par étudiant, exactement comme en 8.6 :

```python
from pathlib import Path

CHEMIN_CSV = Path(__file__).parent / "etudiants.csv"
EN_TETE = "da,prenom,nom,notes"


def sauvegarder_etudiants_csv(chemin, etudiants):
    """Écrit la liste des étudiants dans le fichier CSV, avec l'en-tête."""
    with open(chemin, "w", encoding="utf-8") as fichier:
        fichier.write(EN_TETE + "\n")
        for etudiant in etudiants:
            fichier.write(etudiant.vers_ligne_csv() + "\n")


groupe = [abby, Etudiant("2456789", "Éloi", "Gagnon"), zoe]
groupe[1].ajouter_note(64)
sauvegarder_etudiants_csv(CHEMIN_CSV, groupe)
print("Groupe sauvegardé.")
```

```text
Groupe sauvegardé.
```

## 4. D'une ligne à un objet

Pour le chemin inverse, on découpe la ligne avec `split(",")`, on recrée l'étudiant avec le constructeur, puis on redonne ses notes une à une avec `ajouter_note()` :

```python
def etudiant_depuis_ligne_csv(ligne):
    """Crée un objet Etudiant à partir d'une ligne CSV valide."""
    champs = ligne.strip().split(",")
    etudiant = Etudiant(champs[0], champs[1], champs[2])
    for texte in champs[3].split():
        etudiant.ajouter_note(int(texte))
    return etudiant


copie = etudiant_depuis_ligne_csv("2345678,Abby,Tremblay,85 92\n")
print(copie)
print(copie.notes, f"moyenne {copie.moyenne():.1f}")
```

```text
2345678 - Abby Tremblay
[85, 92] moyenne 88.5
```

- Tout ce qu'on lit dans un CSV est une **chaîne** : contrairement au JSON, il faut convertir chaque note avec `int()`.
- `"85 92".split()` donne `["85", "92"]`, et `"".split()` donne `[]` : un étudiant sans note est géré sans cas particulier.

## 5. Recharger la liste, avec validation

Un fichier CSV est souvent modifié à la main, ou dans Excel. Avant de reconstruire un étudiant, on vérifie la ligne. Une ligne invalide est **ignorée**, avec un message qui donne son **numéro** (l'en-tête est la ligne 1) :

```python
LONGUEUR_DA = 7


def verifier_ligne(ligne):
    """Renvoie un message d'erreur si la ligne CSV est invalide, sinon une chaîne vide."""
    champs = ligne.strip().split(",")
    if len(champs) != 4:
        return f"{len(champs)} colonnes au lieu de 4"
    if len(champs[0]) != LONGUEUR_DA or not champs[0].isdigit():
        return f"DA « {champs[0]} » invalide"
    if champs[1].strip() == "" or champs[2].strip() == "":
        return "prénom ou nom manquant"
    for texte in champs[3].split():
        if not texte.isdigit():
            return f"note « {texte} » invalide"
    return ""


def charger_etudiants_csv(chemin):
    """Renvoie la liste des étudiants du fichier CSV (liste vide si le fichier est absent)."""
    etudiants = []
    try:
        with open(chemin, "r", encoding="utf-8") as fichier:
            fichier.readline()                     # en-tête
            numero = 1
            for ligne in fichier:
                numero += 1
                if ligne.strip() == "":
                    continue                       # ligne vide : ignorée sans message
                erreur = verifier_ligne(ligne)
                if erreur != "":
                    print(f"Ligne {numero} ignorée : {erreur}.")
                else:
                    etudiants.append(etudiant_depuis_ligne_csv(ligne))
    except FileNotFoundError:
        pass                                       # première exécution : aucun étudiant
    return etudiants


groupe = charger_etudiants_csv(CHEMIN_CSV)
print(f"{len(groupe)} étudiant(s) rechargé(s) :")
for etudiant in groupe:
    print(f"  {etudiant}  notes {etudiant.notes}")
```

```text
3 étudiant(s) rechargé(s) :
  2345678 - Abby Tremblay  notes [85, 92]
  2456789 - Éloi Gagnon  notes [64]
  2567890 - Zoé Roy  notes []
```

Si quelqu'un ajoute ces lignes dans Excel ou à la main :

```text

```

```text

```

> 💡 `isdigit()` (voir [Manipulations de chaînes](../Outils/Manipulations%20de%20chaînes.md)) vérifie que le texte ne contient que des chiffres : `int()` ne peut alors plus échouer. Une note de `150` passe la validation, mais elle est refusée par `ajouter_note()`, comme une saisie au clavier.

## 6. Changer de format sans toucher au reste du programme

Le programme complet de la fiche 10.6 ne touche à ses fichiers que par **deux fonctions** : `charger_etudiants()` et `sauvegarder_etudiants()`. Pour passer au CSV, on remplace leur contenu… et c'est tout! Le menu, les saisies et la classe ne changent pas.

```python
def main():
    groupe = charger_etudiants_csv(CHEMIN_CSV)          # au lieu de charger_etudiants(CHEMIN_ETUDIANTS)
    print(f"{len(groupe)} étudiant(s) chargé(s).")
    # ... le reste de main() est identique, avec sauvegarder_etudiants_csv(CHEMIN_CSV, groupe)
```

C'est l'avantage d'avoir **isolé la traduction** dans `vers_dict()` / `vers_ligne_csv()` et dans quelques fonctions de chargement et de sauvegarde.

| | JSON (10.5 et 10.6) | CSV (10.7) |
| --- | --- | --- |
| Ouvrir dans Excel | ❌ | ✅ |
| Types conservés (les notes restent des `int`) | ✅ | ❌ Tout est une chaîne |
| Une liste dans un objet (`notes`) | ✅ Naturel | ⚠️ À coder dans une case (`85 92`) |
| Objets imbriqués (un groupe qui contient des étudiants) | ✅ | ❌ Difficile |
| Traduction | `vers_dict()` + `json.dump()` | `vers_ligne_csv()` + `write()` |

> 📌 **Règle pratique** : JSON pour **conserver** les données d'un programme; CSV pour les **échanger** avec un tableur.

## 7. Pour aller plus loin : le module `csv`

Notre version « à la main » casse si un nom contient une virgule (`Tremblay, fils`). Le module `csv` de la fiche [Module csv](../Outils/Fichiers%20CSV%20-%20Module%20csv.md) règle ce problème : on lui donne une **liste** de champs, et `csv.writer` s'occupe des virgules et des guillemets (et `csv.reader`, à la relecture).

```python
import csv

with open(CHEMIN_CSV, "w", encoding="utf-8", newline="") as fichier:
    ecrivain = csv.writer(fichier)
    ecrivain.writerow(["da", "prenom", "nom", "notes"])
    for etudiant in groupe:
        textes_notes = []
        for note in etudiant.notes:
            textes_notes.append(str(note))
        ecrivain.writerow([etudiant.da, etudiant.prenom, etudiant.nom, " ".join(textes_notes)])
```

## En résumé

- En CSV, une liste d'objets devient un tableau : **une ligne par objet**, une colonne par attribut, avec un en-tête.
- Une liste d'attributs (les notes) se range dans une seule case, avec un autre séparateur (`85 92`).
- `vers_ligne_csv()` traduit un objet en ligne; `etudiant_depuis_ligne_csv()` fait l'inverse.
- Tout ce qu'on lit est une chaîne : on valide chaque ligne, puis on convertit avec `int()`.
- En isolant la traduction dans quelques fonctions, on change de format sans toucher au reste du programme.
