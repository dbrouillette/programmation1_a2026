# Sauvegarder des objets en JSON

## Objectifs

- Comprendre pourquoi `json.dump()` refuse un objet.
- Convertir un objet en dictionnaire avec une méthode `vers_dict()`.
- Sauvegarder une liste d'objets dans un fichier JSON.

> 📋 **Prérequis** : [10.3 - Une liste d'objets](10.3%20-%20Une%20liste%20d'objets.md), le format JSON ([fiche Module json](../Outils/Fichiers%20JSON%20-%20Module%20json.md)) et les dictionnaires en JSON ([9.5](../Cours%2009/9.5%20-%20Les%20dictionnaires%20en%20JSON.md)).

> 🎓 Dans les fiches 10.5 à 10.7, on gère la liste des étudiants d'un groupe-cours : leur DA, leur prénom, leur nom et leurs notes.

## 1. Principe

Les objets vivent dans la **mémoire vive** : quand le programme se termine, ils disparaissent, comme toutes les variables. Pour retrouver la liste des étudiants au prochain démarrage, il faut la **sauvegarder dans un fichier**, puis la **recharger**.

Voici la classe utilisée dans toute la fiche :

```python
class Etudiant:
    """Un étudiant du groupe-cours."""

    def __init__(self, da, prenom, nom):
        self.da = da
        self.prenom = prenom
        self.nom = nom
        self.notes = []

    def ajouter_note(self, note):
        """Ajoute une note, si elle est entre 0 et 100."""
        if 0 <= note <= 100:
            self.notes.append(note)

    def moyenne(self):
        """Renvoie la moyenne des notes, ou 0 s'il n'y en a aucune."""
        if len(self.notes) == 0:
            return 0
        return sum(self.notes) / len(self.notes)

    def __str__(self):
        return f"{self.da} - {self.prenom} {self.nom}"
```

Essayons naïvement de sauvegarder une liste d'étudiants avec `json.dump()` :

```python
import json

abby = Etudiant("2345678", "Abby", "Tremblay")
with open("etudiants.json", "w", encoding="utf-8") as fichier:
    json.dump([abby], fichier)
```

```text
TypeError: Object of type Etudiant is not JSON serializable
```

JSON ne connaît que les listes, les dictionnaires, les chaînes, les nombres, les booléens et `null`. Il ne sait **pas** ce qu'est un `Etudiant`!

## 2. La stratégie : passer par des dictionnaires

On fait la traduction nous-mêmes, dans les deux sens :

```text
Sauvegarder :   objets Etudiant  ──vers_dict()──▶  dictionnaires  ──json.dump()──▶  fichier JSON
Recharger   :   fichier JSON  ──json.load()──▶  dictionnaires  ──etudiant_depuis_dict()──▶  objets Etudiant
```

Un dictionnaire, JSON sait très bien le sauvegarder (cours 9). Il suffit donc de savoir :

1. transformer **un objet en dictionnaire** : c'est le rôle de la méthode `vers_dict()`;
2. transformer **un dictionnaire en objet** : c'est le rôle de la fonction `etudiant_depuis_dict()`.

## 3. D'un objet à un dictionnaire : `vers_dict()`

On ajoute une méthode à la classe. Elle renvoie un dictionnaire qui contient **tous les attributs** nécessaires pour reconstruire l'objet plus tard :

```python
class Etudiant:
    """Un étudiant du groupe-cours."""

    def __init__(self, da, prenom, nom):
        self.da = da
        self.prenom = prenom
        self.nom = nom
        self.notes = []

    def ajouter_note(self, note):
        """Ajoute une note, si elle est entre 0 et 100."""
        if 0 <= note <= 100:
            self.notes.append(note)

    def moyenne(self):
        """Renvoie la moyenne des notes, ou 0 s'il n'y en a aucune."""
        if len(self.notes) == 0:
            return 0
        return sum(self.notes) / len(self.notes)

    def vers_dict(self):
        """Renvoie un dictionnaire qui représente l'étudiant (pour JSON)."""
        return {
            "da": self.da,
            "prenom": self.prenom,
            "nom": self.nom,
            "notes": self.notes,
        }

    def __str__(self):
        return f"{self.da} - {self.prenom} {self.nom}"

abby = Etudiant("2345678", "Abby", "Tremblay")
abby.ajouter_note(85)
abby.ajouter_note(92)
print(abby.vers_dict())
```

```text
{'da': '2345678', 'prenom': 'Abby', 'nom': 'Tremblay', 'notes': [85, 92]}
```

> 📌 On ne sauvegarde **pas** la moyenne : elle se **recalcule** à partir des notes. Sauvegarder une valeur calculée, c'est risquer qu'elle ne corresponde plus aux notes si quelqu'un modifie le fichier.

## 4. Sauvegarder la liste

On construit la liste des dictionnaires avec une boucle, puis on l'écrit avec `json.dump()`, exactement comme au cours 9 :

```python
import json
from pathlib import Path

CHEMIN_ETUDIANTS = Path(__file__).parent / "etudiants.json"

def sauvegarder_etudiants(chemin, etudiants):
    """Écrit la liste des étudiants dans le fichier JSON."""
    donnees = []
    for etudiant in etudiants:
        donnees.append(etudiant.vers_dict())
    with open(chemin, "w", encoding="utf-8") as fichier:
        json.dump(donnees, fichier, indent=4, ensure_ascii=False)

groupe = [
    Etudiant("2345678", "Abby", "Tremblay"),
    Etudiant("2456789", "Éloi", "Gagnon"),
]
groupe[0].ajouter_note(85)
groupe[0].ajouter_note(92)
groupe[1].ajouter_note(64)

sauvegarder_etudiants(CHEMIN_ETUDIANTS, groupe)
print("Groupe sauvegardé.")
```

```text
Groupe sauvegardé.
```

Le fichier `etudiants.json` obtenu :

```json
[
    {
        "da": "2345678",
        "prenom": "Abby",
        "nom": "Tremblay",
        "notes": [
            85,
            92
        ]
    },
    {
        "da": "2456789",
        "prenom": "Éloi",
        "nom": "Gagnon",
        "notes": [
            64
        ]
    }
]
```

> 💡 Le DA est une **chaîne** (`"2345678"`) et non un nombre : on ne fait pas de calculs avec un DA, et une chaîne conserve les zéros au début (`"0123456"`).

## En résumé

- `json.dump()` ne sait pas sauvegarder un objet : `TypeError: Object of type ... is not JSON serializable`.
- On traduit soi-même : objet → dictionnaire → fichier JSON.
- La méthode `vers_dict()` renvoie un dictionnaire qui contient les attributs nécessaires pour recréer l'objet.
- Pour sauvegarder une liste d'objets, on construit la liste de leurs dictionnaires, puis on l'écrit avec `json.dump()`.
- On ne sauvegarde pas les valeurs calculées (une moyenne) : elles se recalculent.
