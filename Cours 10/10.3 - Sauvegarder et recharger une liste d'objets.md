# Sauvegarder et recharger une liste d'objets

## Objectifs

- Comprendre pourquoi `json.dump()` refuse un objet.
- Convertir un objet en dictionnaire avec une méthode `vers_dict()`.
- Sauvegarder une liste d'objets dans un fichier JSON.
- Recharger le fichier et **reconstruire** les objets, en validant les données lues.
- Assembler le tout dans un programme qui conserve ses données d'une exécution à l'autre.

> 📋 **Prérequis** : [10.2 - Une liste d'objets](10.2%20-%20Une%20liste%20d'objets.md), le format JSON ([fiche Module json](../Outils/Fichiers%20JSON%20-%20Module%20json.md)) et les dictionnaires en JSON ([9.3](../Cours%2009/9.3%20-%20Listes%20de%20dictionnaires%20et%20données%20imbriquées.md)).

> 🎓 Dans cette fiche, on gère la liste des étudiants d'un groupe-cours : leur DA, leur prénom, leur nom et leurs notes.

## 1. Principe

Les objets vivent dans la **mémoire vive** : quand le programme se termine, ils disparaissent, comme toutes les variables. Pour retrouver la liste des étudiants au prochain démarrage, il faut la **sauvegarder dans un fichier**, puis la **recharger**.

Voici la classe utilisée dans toute la fiche :

```python
class Etudiant:
    """Un étudiant du groupe-cours."""

    def __init__(self, da, prenom, nom):
        self.da = da
        self.prenom = prenom
        self.nom = nom
        self.notes = []

    def ajouter_note(self, note):
        """Ajoute une note, si elle est entre 0 et 100."""
        if 0 <= note <= 100:
            self.notes.append(note)

    def moyenne(self):
        """Renvoie la moyenne des notes, ou 0 s'il n'y en a aucune."""
        if len(self.notes) == 0:
            return 0
        return sum(self.notes) / len(self.notes)

    def __str__(self):
        return f"{self.da} - {self.prenom} {self.nom}"
```

Essayons naïvement de sauvegarder une liste d'étudiants avec `json.dump()` :

```python
import json

abby = Etudiant("2345678", "Abby", "Tremblay")
with open("etudiants.json", "w", encoding="utf-8") as fichier:
    json.dump([abby], fichier)
```

```text
TypeError: Object of type Etudiant is not JSON serializable
```

JSON ne connaît que les listes, les dictionnaires, les chaînes, les nombres, les booléens et `null`. Il ne sait **pas** ce qu'est un `Etudiant`!

## 2. La stratégie : passer par des dictionnaires

On fait la traduction nous-mêmes, dans les deux sens :

```text
Sauvegarder :   objets Etudiant  ──vers_dict()──▶  dictionnaires  ──json.dump()──▶  fichier JSON
Recharger   :   fichier JSON  ──json.load()──▶  dictionnaires  ──etudiant_depuis_dict()──▶  objets Etudiant
```

Un dictionnaire, JSON sait très bien le sauvegarder (cours 9). Il suffit donc de savoir :

1. transformer **un objet en dictionnaire** : c'est le rôle de la méthode `vers_dict()`;
2. transformer **un dictionnaire en objet** : c'est le rôle de la fonction `etudiant_depuis_dict()`.

## 3. D'un objet à un dictionnaire : `vers_dict()`

On ajoute une méthode à la classe. Elle renvoie un dictionnaire qui contient **tous les attributs** nécessaires pour reconstruire l'objet plus tard :

```python
class Etudiant:
    """Un étudiant du groupe-cours."""

    def __init__(self, da, prenom, nom):
        self.da = da
        self.prenom = prenom
        self.nom = nom
        self.notes = []

    def ajouter_note(self, note):
        """Ajoute une note, si elle est entre 0 et 100."""
        if 0 <= note <= 100:
            self.notes.append(note)

    def moyenne(self):
        """Renvoie la moyenne des notes, ou 0 s'il n'y en a aucune."""
        if len(self.notes) == 0:
            return 0
        return sum(self.notes) / len(self.notes)

    def vers_dict(self):
        """Renvoie un dictionnaire qui représente l'étudiant (pour JSON)."""
        return {
            "da": self.da,
            "prenom": self.prenom,
            "nom": self.nom,
            "notes": self.notes,
        }

    def __str__(self):
        return f"{self.da} - {self.prenom} {self.nom}"


abby = Etudiant("2345678", "Abby", "Tremblay")
abby.ajouter_note(85)
abby.ajouter_note(92)
print(abby.vers_dict())
```

```text
{'da': '2345678', 'prenom': 'Abby', 'nom': 'Tremblay', 'notes': [85, 92]}
```

> 📌 On ne sauvegarde **pas** la moyenne : elle se **recalcule** à partir des notes. Sauvegarder une valeur calculée, c'est risquer qu'elle ne corresponde plus aux notes si quelqu'un modifie le fichier.

## 4. Sauvegarder la liste

On construit la liste des dictionnaires avec une boucle, puis on l'écrit avec `json.dump()`, exactement comme au cours 9 :

```python
import json
from pathlib import Path

CHEMIN_ETUDIANTS = Path(__file__).parent / "etudiants.json"


def sauvegarder_etudiants(chemin, etudiants):
    """Écrit la liste des étudiants dans le fichier JSON."""
    donnees = []
    for etudiant in etudiants:
        donnees.append(etudiant.vers_dict())
    with open(chemin, "w", encoding="utf-8") as fichier:
        json.dump(donnees, fichier, indent=4, ensure_ascii=False)


groupe = [
    Etudiant("2345678", "Abby", "Tremblay"),
    Etudiant("2456789", "Éloi", "Gagnon"),
]
groupe[0].ajouter_note(85)
groupe[0].ajouter_note(92)
groupe[1].ajouter_note(64)

sauvegarder_etudiants(CHEMIN_ETUDIANTS, groupe)
print("Groupe sauvegardé.")
```

```text
Groupe sauvegardé.
```

Le fichier `etudiants.json` obtenu :

```json
[
    {
        "da": "2345678",
        "prenom": "Abby",
        "nom": "Tremblay",
        "notes": [
            85,
            92
        ]
    },
    {
        "da": "2456789",
        "prenom": "Éloi",

        "notes": [

```

> 💡 Le DA est une **chaîne** (`"2345678"`) et non un nombre : on ne fait pas de calculs avec un DA, et une chaîne conserve les zéros au début (`"0123456"`).

## 5. D'un dictionnaire à un objet : `etudiant_depuis_dict()`

À la relecture, `json.load()` renvoie une liste de **dictionnaires**. Pour chacun, on recrée un objet `Etudiant` avec le constructeur, puis on lui redonne ses notes :

```python
def etudiant_depuis_dict(donnees):
    """Crée un objet Etudiant à partir d'un dictionnaire lu dans le fichier JSON."""
    etudiant = Etudiant(donnees["da"], donnees["prenom"], donnees["nom"])
    for note in donnees["notes"]:
        etudiant.ajouter_note(note)
    return etudiant


copie = etudiant_depuis_dict({"da": "2567890", "prenom": "Zoé", "nom": "Roy", "notes": [78, 90]})
print(copie)
print(f"Moyenne : {copie.moyenne():.1f}")
```

```text
2567890 - Zoé Roy
Moyenne : 84.0
```

On repasse par `ajouter_note()` plutôt que d'écrire `etudiant.notes = donnees["notes"]` : ainsi, une note invalide écrite à la main dans le fichier (`150`) est refusée, comme si elle avait été saisie au clavier.

## 6. Recharger la liste, avec validation

Le fichier peut être **absent** (première exécution), **invalide** (erreur de syntaxe JSON) ou **modifié à la main** (une clé oubliée, un DA écrit comme un nombre…). Comme au cours 9, on gère chaque cas, et on ne reconstruit que les étudiants valides :

```python
CLES_ETUDIANT = ["da", "prenom", "nom", "notes"]


def etudiant_valide(donnees):
    """Renvoie True si le dictionnaire a la forme attendue pour un étudiant."""
    if type(donnees) != dict:
        return False
    for cle in CLES_ETUDIANT:
        if cle not in donnees:
            return False
    if type(donnees["da"]) != str or type(donnees["prenom"]) != str or type(donnees["nom"]) != str:
        return False
    if type(donnees["notes"]) != list:
        return False
    for note in donnees["notes"]:
        if type(note) != int:
            return False
    return True


def charger_etudiants(chemin):
    """Renvoie la liste des étudiants du fichier JSON (liste vide en cas de problème)."""
    try:
        with open(chemin, "r", encoding="utf-8") as fichier:
            donnees = json.load(fichier)
    except FileNotFoundError:
        return []                      # première exécution : aucun étudiant
    except json.JSONDecodeError:
        print(f"Avertissement : {chemin.name} est invalide. Groupe vide.")
        return []
    if type(donnees) != list:
        print(f"Avertissement : {chemin.name} ne contient pas une liste. Groupe vide.")
        return []

    etudiants = []
    for i in range(len(donnees)):
        if etudiant_valide(donnees[i]):
            etudiants.append(etudiant_depuis_dict(donnees[i]))
        else:
            print(f"Avertissement : l'étudiant no {i + 1} est invalide et a été ignoré.")
    return etudiants


groupe = charger_etudiants(CHEMIN_ETUDIANTS)
print(f"{len(groupe)} étudiant(s) rechargé(s) :")
for etudiant in groupe:
    print(f"  {etudiant}  moyenne {etudiant.moyenne():.1f}")
```

```text
2 étudiant(s) rechargé(s) :
  2345678 - Abby Tremblay  moyenne 88.5
  2456789 - Éloi Gagnon  moyenne 64.0
```

Les étudiants rechargés sont de **vrais objets** : on peut appeler leurs méthodes (`moyenne()`, `ajouter_note()`) comme s'ils n'avaient jamais quitté la mémoire.

Si quelqu'un écrit le DA d'un étudiant comme un nombre dans le fichier (`"da": 2456789`), ce seul étudiant est ignoré :

```text
Avertissement : l'étudiant no 2 est invalide et a été ignoré.
1 étudiant(s) rechargé(s) :
  2345678 - Abby Tremblay  moyenne 88.5
```

## 7. Le programme complet : charger, travailler, sauvegarder

On retrouve le patron du cours 8 : on **charge** au démarrage, on **travaille** avec les objets en mémoire, et on **sauvegarde** après chaque modification.

```python
def main():
    groupe = charger_etudiants(CHEMIN_ETUDIANTS)
    print(f"{len(groupe)} étudiant(s) chargé(s).")

    choix = -1
    while choix != 0:
        print("\n1. Afficher  2. Ajouter un étudiant  3. Ajouter une note  4. Retirer  0. Quitter")
        choix = lire_entier("Votre choix : ", 0, 4)
        if choix == 1:
            afficher_groupe(groupe)
        elif choix == 2:
            ajouter_etudiant(groupe)
            sauvegarder_etudiants(CHEMIN_ETUDIANTS, groupe)
        elif choix == 3:
            ajouter_note(groupe)
            sauvegarder_etudiants(CHEMIN_ETUDIANTS, groupe)
        elif choix == 4:
            retirer_etudiant(groupe)
            sauvegarder_etudiants(CHEMIN_ETUDIANTS, groupe)
```

## 8. Bonnes pratiques

- ✅ Une méthode `vers_dict()` dans la classe, et une fonction `..._depuis_dict()` pour le chemin inverse : toute la traduction est à un seul endroit.
- ✅ Sauvegarder seulement les **données de base** (DA, nom, notes), jamais les valeurs calculées (moyenne).
- ✅ Recréer les objets avec le **constructeur** et les **méthodes** de la classe : leurs validations s'appliquent aussi aux données lues.
- ✅ Valider la forme des données lues : un fichier JSON peut avoir été modifié à la main.
- ✅ Sauvegarder **après chaque modification** : un programme fermé brusquement ne perd rien.

## En résumé

- `json.dump()` ne sait pas sauvegarder un objet : `TypeError: Object of type ... is not JSON serializable`.
- Pour sauvegarder : chaque objet devient un dictionnaire avec `vers_dict()`, puis la liste de dictionnaires est écrite avec `json.dump()`.
- Pour recharger : `json.load()` renvoie des dictionnaires, que `etudiant_depuis_dict()` retransforme en objets.
- On valide chaque dictionnaire avant de le reconstruire, et on gère `FileNotFoundError` et `json.JSONDecodeError`.
- Patron : charger au démarrage, travailler avec les objets, sauvegarder après chaque modification.
