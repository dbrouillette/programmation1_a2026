# Les méthodes

## Objectifs

- Ajouter des **méthodes** à une classe.
- Appeler une méthode sur un objet.
- Protéger les attributs d'un objet avec des méthodes qui valident.
- Afficher un objet avec `__str__()`.

> 📋 **Prérequis** : [10.1 - Classes et objets : le principe](10.1%20-%20Classes%20et%20objets,%20le%20principe.md).

> 🦊 **Fil conducteur** : dans les fiches 10.1 à 10.4, on programme les renards d'un refuge faunique.

## 1. Définir et appeler une méthode

Une **méthode** est une fonction définie **dans** une classe. Son premier paramètre est toujours `self` : elle a ainsi accès aux attributs de l'objet.

```python
ENERGIE_MAX = 100

class Renard:
    """Un renard du refuge."""

    def __init__(self, nom, couleur, age):
        self.nom = nom
        self.couleur = couleur
        self.age = age
        self.energie = 50
        self.proies = []

    def glapir(self):
        """Renvoie le cri du renard."""
        return f"{self.nom} : Wak wak wak!"

    def chasser(self, proie):
        """Attrape une proie : +20 d'énergie, sans dépasser ENERGIE_MAX."""
        self.proies.append(proie)
        self.energie += 20
        if self.energie > ENERGIE_MAX:
            self.energie = ENERGIE_MAX

    def courir(self, distance):
        """Court distance km (10 d'énergie par km). Renvoie False si le renard est trop fatigué."""
        cout = distance * 10
        if cout > self.energie:
            return False
        self.energie -= cout
        return True

roux = Renard("Roux", "roux", 3)
print(roux.glapir())

roux.chasser("mulot")
roux.chasser("lièvre")
print(f"Proies : {roux.proies}, énergie : {roux.energie}")

print(roux.courir(5))
print(roux.courir(5))
print(f"Énergie : {roux.energie}")
```

```text
Roux : Wak wak wak!
Proies : ['mulot', 'lièvre'], énergie : 90
True
False
Énergie : 40
```

On appelle une méthode avec un point, comme `"roux".upper()` ou `liste.append(5)` : `roux.chasser("mulot")`. À l'intérieur, `self` est alors `roux`.

La première course de 5 km coûte 50 d'énergie : il en reste 40. La deuxième est **refusée** : le renard est trop fatigué, et son énergie ne change pas.

> 💡 Comparons avec un dictionnaire :
>
> | Avec un dictionnaire | Avec un objet |
> | --- | --- |
> | `renard["nom"]` | `renard.nom` |
> | `chasser(renard, "mulot")` | `renard.chasser("mulot")` |
> | `courir(renard, 5)` | `renard.courir(5)` |
>
> Les données et les fonctions qui les manipulent sont maintenant **rangées ensemble**, dans la classe.

> 📌 Une méthode qui **valide** avant de modifier un attribut (comme `courir()`) protège l'objet : l'énergie ne peut jamais devenir négative… à condition de passer par la méthode!

## 2. Afficher un objet : `__str__()`

Par défaut, `print()` d'un objet n'est pas très utile :

```python
print(roux)
```

```text
<__main__.Renard object at 0x000001F3A8C4E0D0>
```

La méthode spéciale `__str__()` indique à Python comment transformer l'objet en chaîne. Elle doit **renvoyer** une chaîne (et non l'afficher) :

```python
class Renard:
    """Un renard du refuge."""

    def __init__(self, nom, couleur, age):
        self.nom = nom
        self.couleur = couleur
        self.age = age
        self.energie = 50
        self.proies = []

    def __str__(self):
        return f"{self.nom}, renard {self.couleur} de {self.age} ans (énergie {self.energie})"

cendre = Renard("Cendre", "argenté", 4)
print(cendre)
print(f"Nouveau pensionnaire : {cendre}")
```

```text
Cendre, renard argenté de 4 ans (énergie 50)
Nouveau pensionnaire : Cendre, renard argenté de 4 ans (énergie 50)
```

## 3. Vocabulaire

| Terme | Définition | Exemple |
| --- | --- | --- |
| **Classe** | Le plan qui décrit une sorte d'objets | `Renard` |
| **Objet** (ou **instance**) | Une chose créée à partir d'une classe | `roux` |
| **Attribut** | Une donnée rangée dans un objet | `roux.energie` |
| **Méthode** | Une fonction définie dans la classe | `roux.chasser("mulot")` |
| **Constructeur** | La méthode `__init__()`, appelée à la création | `Renard("Roux", "roux", 3)` |
| **`self`** | L'objet sur lequel la méthode travaille | `self.proies` |

## 4. Erreurs fréquentes

| Erreur | Symptôme | Correction |
| --- | --- | --- |
| Oublier `self` dans la définition d'une méthode | `TypeError: Renard.glapir() takes 0 positional arguments but 1 was given` | `def glapir(self):` |
| Oublier `self.` devant un attribut | `NameError: name 'energie' is not defined` | `self.energie` |
| Oublier les parenthèses à l'appel | Affiche `<bound method Renard.glapir of ...>` | `roux.glapir()` |
| `__init__` mal écrit (`_init_`, `__int__`) | `TypeError: Renard() takes no arguments` | Deux `_` de chaque côté de `init` |
| `__str__()` qui affiche au lieu de renvoyer | `TypeError: __str__ returned non-string (type NoneType)` | `return f"..."` |

## En résumé

- Une **méthode** est une fonction définie dans la classe; son premier paramètre est `self`.
- On appelle une méthode avec un point : `roux.chasser("mulot")`; à l'intérieur, `self` est `roux`.
- Une méthode qui valide avant de modifier un attribut protège l'objet.
- `__str__()` **renvoie** le texte affiché par `print(objet)` et par les f-strings.
