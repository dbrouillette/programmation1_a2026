# 🖥️ Les sorties en console avec `print()` en Python

## Objectifs

- Comprendre comment afficher des informations à l'écran.
- Connaître les options principales de `print()`.
- Utiliser les `f-strings` pour formater un message.
- Apprendre à afficher plusieurs valeurs et à contrôler les retours à la ligne.

## Syntaxe de base

```python
print("Bonjour !")
print("Bonjour ", end="")
nom = "Alice"
age = 30
print(f"Nom : {nom}, Âge : {age}")
```

## `print()` : options essentielles

**Python propose `print()` pour afficher du texte et des valeurs à l'écran.**

| Syntaxe | Description |
| --- | --- |
| `print(x)` | Affiche `x`, puis ajoute automatiquement un retour à la ligne |
| `print(x, end="")` | Affiche `x` sans retour à la ligne |
| `print(a, b, c)` | Affiche plusieurs valeurs séparées par des espaces |
| `print(..., sep=" - ")` | Utilise un séparateur personnalisé entre les valeurs |
| `print(f"...")` | Affiche une chaîne formatée avec des variables ou expressions |

## Exemples

### Exemple 1 : retour à la ligne automatique

```python
print("Bonjour")
print("le monde!")
```

Résultat :

```text
Bonjour
le monde!
```

### Exemple 2 : sans retour à la ligne

```python
print("Bonjour ", end="")
print("le monde!")
```

Résultat :

```text
Bonjour le monde!
```

### Exemple 3 : séparateur personnalisé

```python
print("Janvier", "Février", "Mars", sep=" - ")
```

Résultat :

```text
Janvier - Février - Mars
```

## Affichage formaté avec les f-strings

Les `f-strings` sont la manière la plus claire et moderne d'afficher une chaîne contenant des variables.

```python
nom = "Maxime"
age = 25
pi_sur_2 = 3.14159265359 / 2
print(f"Nom : {nom}, Âge : {age}")
print(f"pi/2 = {pi_sur_2}, pi (4 décimales) = {pi_sur_2 * 2:.4f}")
```

Résultat :

```text
Nom : Maxime, Âge : 25
pi/2 = 1.570796326795, pi (4 décimales) = 3.1416
```

### Concepts clés des f-strings

- Les expressions sont placées entre `{}`.
- Python évalue le contenu et le remplace dans la chaîne.
- `:.nf` permet de formater un nombre avec `n` décimales.

### Exemple rapide

```python
print(f"{42}")
print(f"{'Bonjour'}")
print(f"Valeur : {2.71828182846:.2f}")
```

## Exemple complet

```python
prenom = "Alice"
age = 30
print("Bonjour", prenom)
print(f"Vous avez {age} ans.")
print("Informations :", prenom, age, sep=" | ")
```

Résultat :

```text
Bonjour Alice
Vous avez 30 ans.
Informations : | Alice | 30
```

## Erreurs fréquentes

- Oublier le préfixe `f` devant les guillemets.
- Oublier les accolades `{}` autour de la variable.
- Confondre les types de guillemets à l'intérieur et à l'extérieur de la chaîne.

## À retenir

- La fonction native `print()` permet d'afficher en console.
- Le paramètre nommé `end` permet de modifier le caractère de fin (par défaut, `end='\n'` (retour de ligne)).
- Le paramètre nommé `sep` personnalise le séparateur entre les valeurs (par défaut, `sep=' '` (espace)).
- Les `f-strings` rendent l'affichage de variables simple et lisible.
