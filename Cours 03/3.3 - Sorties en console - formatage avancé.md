# 3.3 — Sorties en console : formatage avancé (f-strings)

## Objectifs

- Comprendre ce qu'est une **f-string** et comment y insérer des variables.
- Contrôler la **largeur** et l'**alignement** d'un champ affiché.
- Formater des **nombres décimaux**, des **pourcentages** et des **grands nombres**.
- Construire un **tableau lisible** en console.

Tout au long de la section, nous utiliserons un même exemple : un petit **inventaire de fruits et légumes**, avec un nom de produit, un code de produit et un prix.

---

## 1. Qu'est-ce qu'une f-string ?

Une **f-string** (pour *formatted string*) est une chaîne de caractères précédée de la lettre `f`. À l'intérieur, tout ce qui est entre accolades `{ }` est **remplacé par sa valeur** au moment de l'affichage.

```python
print(f"Bienvenue au marché !")
```

Résultat :

```text
Bienvenue au marché !
```

Sans variable, une f-string se comporte comme une chaîne ordinaire. Son intérêt commence dès qu'on y insère des données.

```python
produit = "Pomme"
```

## 4. La largeur d'un champ

Après le nom de la variable, on ajoute un **deux-points** `:` suivi du format désiré.

```python
print(f"{variable:spécificateur}")
```

Le spécificateur le plus simple est un **nombre** : c'est la **largeur minimale** du champ, en caractères. Si la valeur est plus courte, Python complète avec des espaces ; si elle est plus longue, rien n'est coupé.

```python
produit = "Pomme"

print(f"|{produit:24}|")
```

Résultat :

```text
|Pomme                   |
```

<p align="right"><sub><a href="https://pythontutor.com/visualize.html#code=produit%20%3D%20%22Pomme%22%0A%0Aprint%28f%22%7C%7Bproduit%3A24%7D%7C%22%29&cumulative=false&heapPrimitives=nevernest&mode=display&origin=opt-frontend.js&py=311&rawInputLstJSON=%5B%5D&textReferences=false">Exécution...</a></sub></p>

Le mot `Pomme` occupe 5 caractères, et Python en ajoute 19 pour atteindre une largeur de 24.

> 💡 Les barres verticales `|` ne servent qu'à **voir** les limites du champ dans les exemples.

## 6. Le caractère de remplissage (*padding*)

Par défaut, Python remplit l'espace libre avec des **espaces**. On peut choisir un autre caractère en le plaçant **avant** le symbole d'alignement.

```python
produit = "Pomme"

print(f"|{produit:-^24}|")
print(f"|{produit:.<24}|")
print(f"|{produit:*>24}|")
```

Résultat :

```text
|---------Pomme----------|
|Pomme...................|
|*******************Pomme|
```

<p align="right"><sub><a href="https://pythontutor.com/visualize.html#code=produit%20%3D%20%22Pomme%22%0A%0Aprint%28f%22%7C%7Bproduit%3A-%5E24%7D%7C%22%29%0Aprint%28f%22%7C%7Bproduit%3A.%3C24%7D%7C%22%29%0Aprint%28f%22%7C%7Bproduit%3A%2A%3E24%7D%7C%22%29&cumulative=false&heapPrimitives=nevernest&mode=display&origin=opt-frontend.js&py=311&rawInputLstJSON=%5B%5D&textReferences=false">Exécution...</a></sub></p>

La lecture se fait dans l'ordre : `-` est le caractère de remplissage, `^` l'alignement, `24` la largeur.

## 7. Les nombres décimaux : `:.2f`

Un prix s'écrit avec **deux décimales**, toujours, même quand elles valent zéro. Le spécificateur `.2f` s'en charge :

- `.2` : deux chiffres après le point ;
- `f` : afficher la valeur en notation décimale *(float)*.

```python
prix = 2.5

print(f"Prix brut    : {prix}")
print(f"Prix formaté : {prix:.2f} $")
```

Résultat :

```text
Prix brut    : 2.5
Prix formaté : 2.50 $
```

Le formatage **arrondit** au besoin :

```python
prix = 1.9999

print(f"{prix:.2f}")
```

Résultat :

```text
2.00
```

## 8. Combiner largeur, alignement et décimales : `:>10.2f`

Les spécificateurs se combinent, dans l'ordre : **alignement**, puis **largeur**, puis **décimales**.

```python
prix = 3.5

print(f"|{prix:>10.2f}|")
```

Résultat :

```text
|      3.50|
```

<p align="right"><sub><a href="https://pythontutor.com/visualize.html#code=prix%20%3D%203.5%0A%0Aprint%28f%22%7C%7Bprix%3A%3E10.2f%7D%7C%22%29&cumulative=false&heapPrimitives=nevernest&mode=display&origin=opt-frontend.js&py=311&rawInputLstJSON=%5B%5D&textReferences=false">Exécution...</a></sub></p>

Décortiquons `{prix:>10.2f}` :

| Morceau | Signification |
| --- | --- |
| `prix` | la variable à afficher |
| `:` | début du spécificateur de format |
| `>` | aligner à **droite** |
| `10` | réserver une largeur de **10 caractères** |
| `.2f` | afficher le nombre avec **2 décimales** |

C'est la formule à retenir pour une colonne de prix : les points décimaux s'alignent parfaitement les uns sous les autres.

## 10. Le pourcentage : `:.1%`

Le spécificateur `%` multiplie la valeur par 100 et ajoute le symbole `%`. Le chiffre avant le `%` indique le nombre de décimales.

```python
rabais = 0.155

print(f"Rabais : {rabais:.1%}")
print(f"Rabais : {rabais:.0%}")
```

Résultat :

```text
Rabais : 15.5%
Rabais : 16%
```

<p align="right"><sub><a href="https://pythontutor.com/visualize.html#code=rabais%20%3D%200.155%0A%0Aprint%28f%22Rabais%20%3A%20%7Brabais%3A.1%25%7D%22%29%0Aprint%28f%22Rabais%20%3A%20%7Brabais%3A.0%25%7D%22%29&cumulative=false&heapPrimitives=nevernest&mode=display&origin=opt-frontend.js&py=311&rawInputLstJSON=%5B%5D&textReferences=false">Exécution...</a></sub></p>

## 12. Une expression ou un calcul dans une f-string

Les accolades n'acceptent pas seulement des variables : elles acceptent **n'importe quelle expression Python**.

```python
print(f"Nom en majuscules : {'pomme'.upper()}")
```

Résultat :

```text

Prix avec taxes : 1.44 $
Nom en majuscules : POMME
```

## 13. Déboguer avec `{variable=}`

En ajoutant un `=` après le nom de la variable, Python affiche **le nom ET la valeur**. C'est un outil de débogage très pratique.

```python
produit = "Carotte"
prix = 1.10

print(f"{produit=}")
print(f"{prix=}")
print(f"{prix * 3=:.2f}")
```

Résultat :

```text
produit='Carotte'
prix=1.1
prix * 3=3.30
```

## 14. Tableau synthèse

| Syntaxe | Description | Exemple Python | Résultat |
| --- | --- | --- | --- |
| `{variable}` | Insère la valeur de la variable | `print(f"{produit}")` | `Pomme` |
| `{v1} {v2}` | Insère plusieurs variables | `print(f"{produit} {code}")` | `Pomme FRU-001` |
| `:24` | Largeur minimale de 24 caractères | `print(f"[{produit:24}]")` | `[Pomme                   ]` |
| `:<24` | Aligné à gauche sur 24 caractères | `print(f"[{produit:<24}]")` | `[Pomme                   ]` |
| `:^24` | Centré sur 24 caractères | `print(f"[{produit:^24}]")` | `[         Pomme          ]` |
| `:>24` | Aligné à droite sur 24 caractères | `print(f"[{produit:>24}]")` | `[                   Pomme]` |
| `:-^24` | Centré, rempli avec des tirets | `print(f"[{produit:-^24}]")` | `[---------Pomme----------]` |
| `:.2f` | Nombre décimal à 2 décimales | `print(f"{prix:.2f}")` | `1.25` |
| `:>10.2f` | Aligné à droite, largeur 10, 2 décimales | `print(f"[{prix:>10.2f}]")` | `[      1.25]` |
| `:,` | Séparateur de milliers | `print(f"{1234567:,}")` | `1,234,567` |
| `:,.2f` | Milliers et 2 décimales | `print(f"{1234.5:,.2f}")` | `1,234.50` |
| `:.1%` | Pourcentage à 1 décimale | `print(f"{0.155:.1%}")` | `15.5%` |
| `:0>6` | Rempli de zéros sur 6 caractères | `print(f"{42:0>6}")` | `000042` |
| `{calcul}` | Expression évaluée directement | `print(f"{2 * 3}")` | `6` |
| `{variable=}` | Nom et valeur (débogage) | `print(f"{prix=}")` | `prix=1.25` |

*Dans ce tableau, les crochets `[ ]` remplacent les barres verticales `|`, qui servent déjà à séparer les colonnes du tableau Markdown. Dans ton code, tu peux utiliser l'un ou l'autre.*

### Pourquoi 76 ?

Chaque ligne du tableau est composée de :

- 3 colonnes de **24** caractères chacune → 72 ;
- 4 barres verticales `|` → 4.

Total : **76** caractères. C'est pourquoi `"-" * 76` produit une ligne exactement de la bonne longueur.

### Le rôle de chaque colonne

| Colonne | Format | Pourquoi |
| --- | --- | --- |
| Produit | `:<24` | Le texte se lit mieux aligné à **gauche** |
| Code | `:^24` | Un code court est agréable **centré** |
| Prix | `:>24.2f` | Les nombres s'alignent à **droite**, décimales alignées |


Résultat :

## 16. À retenir

> ### 📌 À retenir — les f-strings
>
> - Une f-string commence par **`f`** avant les guillemets : `f"..."`. Sans ce `f`, rien n'est remplacé.
> - Une variable s'insère avec **`{variable}`** ; on peut en mettre autant qu'on veut.
> - Le format s'écrit après un **deux-points** : `{variable:format}`.
> - L'ordre du format est : **remplissage**, **alignement**, **largeur**, **décimales** → `{prix:*>10.2f}`.
> - Alignements : **`<`** à gauche, **`^`** au centre, **`>`** à droite. Précise-le **toujours**.
> - `.2f` = deux décimales (idéal pour des prix), `,` = séparateur de milliers, `.1%` = pourcentage.
> - `{variable=}` affiche le nom et la valeur : pratique pour **déboguer**.
> - Pour un tableau : la même largeur pour toutes les cellules d'une colonne, et une ligne de séparation avec `print("-" * n)`.
