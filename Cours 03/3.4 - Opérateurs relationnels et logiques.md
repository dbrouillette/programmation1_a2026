# Opérateurs relationnels (de comparaison) et opérateurs logiques en Python

## Objectifs

- Comprendre comment comparer des valeurs en Python.
- Connaître les opérateurs relationnels et logiques de base.
- Savoir combiner des comparaisons avec `and`, `or` et `not`.
- Utiliser les parenthèses pour clarifier les expressions.

## 1. Opérateurs relationnels (de comparaison)

Les opérateurs de comparaison permettent de **comparer deux valeurs**. Ils retournent un booléen (`True` ou `False` — **notez la majuscule**).

|Opérateur|Signification|Exemple (`a = 5, b = 3`)|Résultat|
|:---:|---|:---:|:---:|
|`>`|Supérieur à|`a > b`|`True`|
|`<`|Inférieur à|`a < b`|`False`|
|`>=`|Supérieur ou égal à|`a >= b`|`True`|
|`<=`|Inférieur ou égal à|`a <= b`|`False`|
|`==`|Égal à|`a == b`|`False`|
|`!=`|Différent de|`a != b`|`True`|

### ATTENTION : la comparaison de valeurs du type `float`

Les nombres décimaux (`float`) sont stockés en mémoire dans une représentation binaire qui ne peut pas toujours représenter exactement une valeur décimale. Résultat : une suite de calculs qui devrait mathématiquement donner un nombre exact peut donner une valeur *presque* identique, mais pas parfaitement égale. On ne devrait donc **jamais** utiliser `==` ou `!=` pour comparer deux `float`.

```python
a = 0.1 + 0.2
b = 0.3
print(a)          # 0.30000000000000004 (!)
print(a == b)     # False (!)
```

Même si `a` et `b` semblent égaux à l'oeil, la comparaison `==` retourne `False`, car les erreurs d'arrondi accumulées lors du calcul binaire font que `a` n'est pas *exactement* égal à `b`.

#### LA SOLUTION : `math.isclose()`

Pour comparer deux `float`, on vérifie plutôt qu'ils sont *suffisamment proches* l'un de l'autre, à l'aide de la fonction `isclose()` du module `math` :

```python
import math     # instruction d'importation

a = 0.1 + 0.2
b = 0.3
print(math.isclose(a, b))  # True
```

<p align="right"><sub><a href="https://pythontutor.com/visualize.html#code=import%20math%20%20%20%20%20%23%20instruction%20d%27importation%0A%0Aa%20%3D%200.1%20%2B%200.2%0Ab%20%3D%200.3%0Aprint%28math.isclose%28a%2C%20b%29%29%20%20%23%20True&cumulative=false&heapPrimitives=nevernest&mode=display&origin=opt-frontend.js&py=311&rawInputLstJSON=%5B%5D&textReferences=false">Exécution...</a></sub></p>

`math.isclose(a, b)` retourne `True` si `a` et `b` sont assez proches pour être considérés égaux, selon une tolérance raisonnable définie par défaut (une tolérance relative de `1e-9`, ajustable avec le paramètre `rel_tol`). C'est la façon recommandée de comparer des `float` en Python, plutôt que d'écrire soi-même une comparaison du type `abs(a - b) < 0.0001`.

Pour vérifier que deux `float` sont **différents** (l'équivalent de `!=`), il suffit d'inverser le résultat avec `not` :

```python
print(not math.isclose(a, b))  # False, car a et b sont considérés égaux
```

## 2. Opérateurs logiques

Les opérateurs logiques permettent de **combiner des expressions booléennes**.

⚠️ Python utilise des mots-clés en anglais : `or`, `and`, `not`.

|Opérateur Python|Nom|Description|
|:---:|---|---|
|`or`|OU logique|`True` si au moins une des deux expressions est vraie|
|`and`|ET logique|`True` si les deux expressions sont vraies|
|`not`|Négation|Inverse la valeur booléenne|

### Exemples

```python
age = 20
est_etudiant = True
print(age >= 18 and est_etudiant)  # True
print(age < 18 or est_etudiant)     # True
print(not est_etudiant)             # False
```

## 3. Tables de vérité

### 3.1 OU logique (`or`)

|Opérande gauche|OU|Opérande droite|Résultat|
|---:|:---:|:---|:---:|
|`True`|`or`|`True`|`True`|
|`True`|`or`|`False`|`True`|
|`False`|`or`|`True`|`True`|
|`False`|`or`|`False`|`False`|

### 3.2 ET logique (`and`)

|Opérande gauche|ET|Opérande droite|Résultat|
|---:|:---:|:---|:---:|
|`True`|`and`|`True`|`True`|
|`True`|`and`|`False`|`False`|
|`False`|`and`|`True`|`False`|
|`False`|`and`|`False`|`False`|

### 3.3 Négation logique (`not`)

|Négation|Opérande|Résultat|
|---:|:---:|:---:|
|`not`|`True`|`False`|
|`not`|`False`|`True`|

## 4. Priorités des opérateurs

> **RAPPEL** : [Priorités des opérateurs](https://docs.python.org/fr/3.14/reference/expressions.html#operator-precedence)

Si une expression contient plusieurs opérateurs logiques, Python applique dans l'ordre :

1. `not`
2. les comparaisons (`<`,`>`,`<=`,`>=`,`==`,`!=`)
3. `and`
4. `or`

```python
a = 5
b = 3
c = 10
print(a > b and b < c or a == 5)
```

## 5. Exemple complet

```python
score = 15
est_adulte = True
if score >= 10 and est_adulte:
    print("Accès autorisé")
elif score >= 10 and not est_adulte:
    print("Accès autorisé avec accompagnement")
else:
    print("Accès refusé")
```

## À retenir

- `>` , `<` , `>=` , `<=` , `==` , `!=` comparent des valeurs et retournent `True` ou `False`.
- `and`, `or` et `not` permettent de combiner des tests.
- Les parenthèses améliorent la lisibilité des expressions logiques complexes.
- `=` est une affectation, `==` est une comparaison.
