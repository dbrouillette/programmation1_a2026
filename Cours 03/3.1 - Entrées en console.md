# Les entrées en console Python

## Objectifs

- Comprendre comment lire une saisie au clavier.
- Savoir que `input()` retourne toujours une chaîne de caractères (`str`).
- Apprendre à convertir la saisie en `int` ou `float` quand nécessaire.
- Connaître les erreurs courantes liées à la conversion.

## La fonction `input()`

> **Référence** : Voir la [documentation officielle](https://docs.python.org/fr/3.14/library/functions.html#input) de la fonction `input()`.

La fonction `input()` est une **fonction native** de Python : elle est disponible sans importation.

> **Syntaxe** : `valeur_saisie = input(message_de_saisie)`  
où le paramètre `message_de_saisie` est une chaîne de caractère qui est affichée lors de la saisie.

Lors de l'utilisation de cette fonction, le programme marque une pause après l'affichage du message de saisie et reprend quand l'utilisateur valide la saisie avec la touche `ENTRÉE`.

Le code suivant

```python
nom = input("Quel est ton nom ? ")
# le programme affiche "Quel est ton nom ? " puis attend la saisie de l'utilsateur et la stocke 
# dans la variable « nom »
```

Produit cet affichage, où le `█` représente la position du curseur à l'endroit où l'utilisateur peut commencer à taper une entrée.

```text
Quel est ton nom ? █
```

## Valeur de retour

La fonction `input()` **retourne toujours une donnée de type `str`**. Peu importe ce que l'utilisateur tape, le résultat est **toujours une chaîne de caractères**.

```python
age = input("Quel est ton âge ? ")
# -> l'utilisateur tape son âge correctement en utilisant des chiffres
print(f"Bonjour {nom}!")
print(type(age))  # <class 'str'> — même si l'utilisateur a tapé par exemple "25"!
```

## Conversion de type d'une entrée console

Comme la fonction que nous utilisons pour faire les saisies console ne retourne que le type `str`, alors en cas de besoin d'un nombre, il faut convertir soi-même la chaîne saisie :

### Deux fonctions de conversion numérique : `int()` et `float()`

Les fonctions `int()` et `float()` sont aussi des **fonctions natives** de Python : elles **convertissent une chaîne de caractères** (ou un autre nombre) **en valeur numérique**, respectivement en nombre entier et en nombre décimal.

> **Syntaxe** : `valeur_entiere = int(valeur_a_convertir)`  
> **Syntaxe** : `valeur_decimale = float(valeur_a_convertir)`  
où le paramètre `valeur_a_convertir` est la valeur (souvent une chaîne de caractères) à transformer en nombre.

```python
# Conversion en nombre entier avec int()
nb_entier = int('18')
print(nb_entier)        # 18
print(type(nb_entier))  # <class 'int'>

# Conversion en nombre réel avec float()
nb_reel = float('11.43')
print(nb_reel)          # 11.43
print(type(nb_reel))    # <class 'float'>
```

## Saisie et conversion "2 en 1"

Il est possible de « composer » la saisie et la conversion dans une seule instruction en passant en argument à `int()` ou `float()` directement un appel à `input()`.

```python
# Saisie et conversion composée
age = int(input("Quel est ton âge ? "))       # saisie + conversion en entier
prix = float(input("Quel est le prix ? "))    # saisie + conversion en nombre réel
```

> **Remarque** : il se peut que des erreurs de type `ValueError` soient générées si la conversion par `int()` ou `float()` échoue. Nous verrons plus tard comment gérer correctement ces erreurs d'exécution potentielles.

```python
age = int(input("Quel est ton âge ? "))
# l'utilisateur saisit délibérément le mot « non »,
# ce qui produit l'erreur suivante

# Traceback (most recent call last):
#   File "c:\Cours 03\test.py", line 31, in <module>
#     int(input("Quel est ton âge ? "))
#     ~~~^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
# ValueError: invalid literal for int() with base 10: 'non'
```

## Lire différents types de données

| Code Python | Description |
| --- | --- |
| `nom = input("...")` | Lit une ligne complète (texte) |
| `age = int(input("..."))` | Lit un entier |
| `prix = float(input("..."))` | Lit un nombre à virgule |

## Remarques importantes

1. `input()` lit **toujours une ligne complète**, y compris les espaces.
2. Le message passé à `input("...")` s'affiche automatiquement avant la saisie.
3. Si on souhaite saisir des données numériques, on convertit la saisie avec `int()` pour convertir en entier ou `float()` pour convertir en réel.
4. Si l'utilisateur tape un texte qui ne peut pas être converti (`float("abc")` par exemple), Python lève un `ValueError`.

## Exemple complet

```python
nom = input("Quel est ton nom ? ")
age = int(input("Quel est ton âge ? "))
print(f"Bonjour {nom}, tu as {age} ans.")
```

## À retenir

- `input()` lit du texte et retourne une `str`.
- Pour obtenir un entier, utiliser `int(input(...))`.
- Pour obtenir un nombre décimal, utiliser `float(input(...))`.
- Les conversions peuvent produire une `ValueError` si la saisie n'est pas au bon format.
