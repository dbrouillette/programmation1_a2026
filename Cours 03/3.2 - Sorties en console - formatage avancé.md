# Documentation sur le formatage des f-strings en Python

## Objectifs

- Comprendre la syntaxe des spécificateurs de format dans les f-strings.
- Savoir aligner et espacer du texte affiché.
- Apprendre à formater des nombres décimaux avec un nombre précis de décimales.

En Python, les **f-strings** permettent d'afficher du texte formaté avec une syntaxe simple : l'expression et son format se trouvent directement à l'intérieur des accolades `{ }`, dans la chaîne elle-même.

## Syntaxe de base

```python
print(f"texte {expression:spec_de_format} texte")
```

- **`expression`** : la variable ou l'expression à afficher.
- **`spec_de_format`** (optionnelle, après le `:`) : contrôle l'alignement, la largeur, le nombre de décimales, etc.

---

## Table des spécificateurs de format

| Spécificateur (f-string) | Résultat |
| --- | --- |
| `{valeur}` | Entier affiché tel quel |
| `{valeur:f}` (6 décimales par défaut) | `3.140000` |
| `{valeur:.nf}` | `n` décimales |
| `{valeur}` | Chaîne de caractères |
| `{valeur}` | Caractère (un `str` de longueur 1 en Python) |

*Remarque : `print()` ajoute déjà un retour à la ligne par défaut, donc il n'y a pas de spécificateur particulier à retenir pour un saut de ligne.*

---

## Largeur et alignement

On peut définir une largeur minimale pour l'affichage d'un champ à l'aide de `<` (gauche), `>` (droite) ou `^` (centré), suivi du nombre de caractères.

### Alignement à droite

Pour aligner à droite, on utilise le symbole `>` dans le spécificateur de format.

```python
print(f"|{'Python':>10}|")
```

Résultat :

```text
|    Python|
```

### Alignement à gauche

Pour aligner à droite, on utilise le symbole `<` dans le spécificateur de format.

```python
print(f"|{'Python':<10}|")
```

Résultat :

```text
|Python    |
```

### Alignement centré

Pour aligner au centre, on utilise le symbole `^` dans le spécificateur de format.

```python
print(f"|{'Python':^10}|")
```

Résultat :

```text
|  Python  |
```

*Remarque : en Python, il est recommandé de **toujours préciser** `<`, `>` ou `^` explicitement pour définir l'alignement, car selon que la donnée à afficher est textuelle ou non.*

---

## Espacements avec des entiers

```python
print(f"|{1:>5}|{23:>5}|{456:>5}|")
```

Résultat :

```text
|    1|   23|  456|
```

---

## Zéros devant les nombres (remplissage ou *padding*)

```python
print(f"|{7:05}|{123:05}|")
```

Résultat :

```text
|00007|00123|
```

---

## Formatage des nombres flottants

### Fixer le nombre de décimales

```python
print(f"|{3.14159:.2f}|{2.5:.3f}|")
```

Résultat :

```text
|3.14|2.500|
```

### Largeur et précision combinées

```python
print(f"|{3.14159:8.2f}|{123.456:8.2f}|")
```

Résultat :

```text
|    3.14|  123.46|
```

---

## Exemple complet : tableau formaté

```python
produits = [("Pomme", 1.25, 10), ("Banane", 0.75, 5), ("Orange", 2.50, 3)]

print(f"{'Produit':<10} {'Prix':>10} {'Quantité':>10}")
for nom, prix, quantite in produits:
    print(f"{nom:<10} {prix:>10.2f} {quantite:>10}")
```

Résultat :

```text
Produit          Prix   Quantité
Pomme            1.25         10
Banane           0.75          5
Orange           2.50          3
```

*Ne t'en fais pas si la boucle `for` ci-dessus n'est pas encore claire — nous l'aborderons dans un cours ultérieur. Concentre-toi pour l'instant sur le formatage des f-strings.*

---

## Résumé

- `{valeur:<n}` : aligner à gauche une valeur dans un champ de largeur `n`.
- `{valeur:>n}` : aligner à droite une valeur dans un champ de largeur `n`.
- `{valeur:^n}` : centrer une valeur dans un champ de largeur `n`.
- `{valeur:0n}` : remplir un nombre de zéros jusqu'à `n` caractères.
- `{valeur:m.nf}` : afficher un flottant sur `m` espaces avec `n` décimales.
