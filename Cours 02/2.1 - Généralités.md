# Structure d'un programme Python

## Objectifs

- Comprendre la structure d'un script Python.
- Voir un exemple de programme complet.
- Apprendre ce qu'est une instruction et un commentaire.
- Savoir pourquoi Python est sensible à la casse.

## Exemple complet : `bonjour.py`

```python
# Auteur  : Maxime Faucher
# Date    : 2025/08/21
# Sujet   : Premier programme en Python

# Afficher un message en console
print("Bonjour le monde!")
```

Ce programme affiche le texte `Bonjour le monde!` dans le terminal.

## Python est sensible à la casse

**Python distingue les majuscules et les minuscules.**

Par exemple :

```python
print("Bonjour")
Print("Bonjour")
```

La première ligne fonctionne, la seconde provoque une erreur car `Print` nest pas la même chose que `print`.

## Commentaires

Un commentaire commence par `#`. Python ignore tout ce qui suit ce symbole sur la même ligne.

### Commentaire sur une ligne

```python
# Ceci est un commentaire
print("Bonjour le monde!")  # commentaire après une instruction
```

### Plusieurs lignes de commentaires

Python na pas de syntaxe spéciale pour les commentaires sur plusieurs lignes. On utilise simplement plusieurs lignes commençant par `#`.

```python
# Auteur : Maxime
# Date   : 2026/08/11
# Sujet  : Explication du code
```

*Remarque : on voit parfois des chaînes entre triples guillemets (`"""..."""`), mais ce sont des chaînes de documentation (`docstrings`), pas des commentaires.*

## Structure minimale dun programme

Un fichier Python peut contenir des instructions directement, sans classe ni fonction :

```python
print("Bonjour le monde!")
```

Cest un programme complet et valide.

## Point dentrée

Python exécute les instructions du fichier dans lordre, de haut en bas.

```python
print("Cette ligne s'exécute en premier")
print("Cette ligne s'exécute en second")
```

La convention `if __name__ == "__main__":` sert à définir un point dentrée explicite dans des programmes plus avancés, mais ce nest pas nécessaire pour commencer.

## Instruction et `print()`

```python
# Afficher un message en console
print("Bonjour le monde!")
```

- `print()` est une fonction native de Python.
- Elle affiche une chaîne de caractères à lécran.
- Les instructions en Python ne se terminent pas par un point-virgule.

## Nomenclature en Python

Voici quelques règles de base (voir [PEP 8](https://peps.python.org/pep-0008/)) :

1. Utiliser `snake_case` pour les noms de variables et fonctions.
2. Choisir un nom clair et significatif.
3. Commencer par une lettre ou un `_`, jamais par un chiffre.
4. Ne pas utiliser un mot réservé du langage (`class`, `for`, `if`, etc.).

Exemple : `nb_etudiants` plutôt que `nbEtudiants`.

## Indentation

En Python, lindentation est importante : elle délimite les blocs de code.

Une indentation incohérente provoque une erreur.
