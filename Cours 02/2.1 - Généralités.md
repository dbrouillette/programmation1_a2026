# Structure d'un programme Python

## Objectifs

- Comprendre la structure d'un script Python.
- Voir un exemple de programme complet.
- Apprendre ce qu'est une instruction et un commentaire.
- Savoir pourquoi Python est sensible à la casse.

## Exemple complet d'un programme : `bonjour.py`

```python
# Auteur  : Maxime Faucher
# Date    : 2025/08/21
# Sujet   : Premier programme en Python

# Afficher un message en console
print("Bonjour le monde!")
```

Ce programme affiche le texte `Bonjour le monde!` dans le terminal. Les lignes 1, 2, 3 et 5 sont des **commentaires**. La ligne 6 contient une **instruction Python valide**, un appel à la fonction native `print()` du langage.

## Python est sensible à la casse

**Python distingue les majuscules et les minuscules.**

Dans l'exemple suivant, une seule des 2 instructions est valide :

```python
print("Bonjour")    # valide
Print("Bonjour")    # non valide, la fonction Print() n'existe pas
```

La première ligne fonctionne, la seconde provoque une erreur car `Print` n'est pas la même chose que `print`.

## Commentaires

Un commentaire commence par `#`. Python ignore tout ce qui suit ce symbole sur la même ligne.

### Commentaire sur une ligne

```python
# Ceci est un commentaire
print("Bonjour le monde!")  # commentaire après une instruction
```

### Plusieurs lignes de commentaires

Python na pas de syntaxe spéciale pour les commentaires sur plusieurs lignes. On utilise simplement plusieurs lignes commençant par `#`.

```python
# Auteur : Maxime
# Date   : 2026/08/11
# Sujet  : Explication du code
```

### Commentaires de documentation

> **Remarque** : on voit parfois des chaînes entre triples guillemets (`"""..."""`), mais ce sont des chaînes de documentation (`docstrings`), pas des commentaires.

```python
"""
Ceci est une chaîne de documentation (docstring) en Python.

Ces chaînes peuvent occuper plusieurs lignes.

"""
```

## Structure minimale dun programme

Un fichier Python peut contenir des instructions directement, sans avoir à déclarer une classe (comme en Java) ou une fonction (comme en C++) :

```python
print("Bonjour le monde!")
```

Le code ci-haut est un programme complet et valide en Python.

## Point d'entrée

Python exécute les instructions du fichier dans l'ordre, de haut en bas.

```python
print("Cette ligne s'exécute en premier")
print("Cette ligne s'exécute en second")
```

> **Remarque** : La convention `if __name__ == "__main__":` sert à définir un point d'entrée explicite dans des programmes plus avancés, mais ce nest pas nécessaire de l'utiliser pour commencer.

## Instruction Python

> **Définition** : Dans un programme informatique, une **instruction** est une commande élémentaire écrite dans un langage de programmation qui indique à l'ordinateur ce qu'il doit faire.

```python
# Afficher un message en console
print("Bonjour le monde!")
```

- `print()` est une fonction native de Python.
- Elle affiche une chaîne de caractères à l'écran.
- Les instructions en Python occupent généralement une seule ligne de code.

### Comment reconnaître une instruction?

Une instruction Python :

- commence souvent en début de ligne;
- indique une action simple à réaliser;
- se termine généralement à la fin de la ligne (contrairement à Java, il n'y a pas de point-virgule obligatoire);
- peut être simple ou composée de plusieurs lignes lorsque nécessaire.

```python
print("Bonjour")

age = 18
```

Ce code contient 2 instructions.

```python
x = 10
y = 20
print(x + y)
```

Ce code contient 3 instructions.

#### Plusieurs instructions sur une même ligne

En Python, on peut séparer plusieurs instructions à l'aide d'un point-virgule (`;`) :

```python
x = 10; y = 20; print(x + y)
```

Dans l'exemple ci-haut, il y a **trois instructions** sur **une seule ligne**. Cependant, cette pratique est généralement **déconseillée** car elle **réduit la lisibilité du code**. Il est préférable d'écrire les 3 instructions sur 3 lignes.

#### Une seule instruction sur plusieurs lignes

Python permet aussi d'étaler une instruction sur plusieurs lignes.

##### Avec des parenthèses

```python
total = (
    nombre1
    + nombre2
    + nombre3
    + nombre4
)
```

L'affectation à `total` constitue une seule instruction, même si elle occupe plusieurs lignes.

##### Avec une barre oblique inversée (`\`)

```python
total = nombre1 + nombre2 + \
nombre3 + nombre4
```

Cette écriture est valide, mais les parenthèses sont généralement préférées.

## Nomenclature en Python

Voici quelques règles de base (voir [PEP 8](https://peps.python.org/pep-0008/)) pour la nomenclature Python :

1. Utiliser `snake_case` pour les noms de variables et fonctions.
2. Choisir un nom clair et significatif.
3. Commencer par une lettre ou un `_`, jamais par un chiffre.
4. Ne pas utiliser un mot réservé du langage (`class`, `for`, `if`, etc.).

Exemple : `nb_etudiants` plutôt que `nbEtudiants`.

## Indentation

En Python, l'indentation est importante : elle délimite les blocs de code.

Une indentation incohérente provoque une erreur.
