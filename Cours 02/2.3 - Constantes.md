# Les constantes en Python

## Objectifs

- Comprendre ce que signifie une constante en Python.
- Savoir pourquoi il n'existe pas de mot-clé dédié aux constantes.
- Connaître la convention `SCREAMING_SNAKE_CASE`.
- Utiliser les constantes pour rendre le code plus lisible.

## Pas de mot-clé dédié

**Python n'a aucun mot-clé pour déclarer une constante.** Rien n'empêche techniquement de modifier la valeur d'une « *constante* » Python après sa création — l'interpréteur ne signalera **aucune erreur**. Ce qu'on appelle constante en Python peut être vu comme une **variable de programme**, c'est-à-dire une variable initialisée en début de fichier et ayant une portée globale.

Une constante en Python est donc une **convention entre programmeurs**, pas une règle du langage.

## Définition

> En Python, une **constante** (ou **variable de programme**) est **une variable dont la valeur ne devrait jamais être modifiée après son initialisation**.

Malheureusement, Python n'offre aucune garantie que la valeur restera toujours la même. Cette responsabilité est celle des développeurs.

```python
NOMBRE_DE_QUESTIONS = 10
NOMBRE_DE_QUESTIONS = 12  # Python ne bloquera pas ceci. C'est à toi de ne pas le faire!
```

## Nomenclature

Pour les quantités constantes en Python, c'est la convention `SCREAMING_SNAKE_CASE` qui est utilisée.

- Le nom doit être **significatif**.
- Utiliser des **lettres majuscules** ou des **chiffres**.
- Séparer les mots par des **soulignements** `_`.

### Exemples de noms

Voici des exemples de noms pour des variables de programme / constantes :

- `PI`
- `TAUX_TPS`
- `NOMBRE_MAX_ETUDIANTS`
- `TOP_5`
- `51E_ETAT`
- `AREA_51_LATITUDE`

## Exemples concrets

```python
NOMBRE_DE_QUESTIONS = 10
PI = 3.14159265359
VITESSE_LUMIERE = 299792458
```

Les constantes sont souvent définies en haut d'un fichier ou au début d'un module.

## Pourquoi utiliser une constante ?

Les constantes permettent de :

- donner un nom clair à une valeur utilisée plusieurs fois ;
- rendre le code plus lisible ;
- faciliter la maintenance si la valeur change.

```python
TAUX_TAXE = 0.14975
prix_ht = 100
prix_ttc = prix_ht * (1 + TAUX_TAXE)
```

## Bonnes pratiques

- Déclarer les constantes en haut du fichier.
- TOUJOURS se référer au nom de la constante, JAMAIS à sa valeur.
- Ne réaffecte pas une variable en `SCREAMING_SNAKE_CASE`.
- Utilise des noms explicites.

## Exemple avec un module standard

Certains modules Python fournissent déjà des constantes. Par exemple :

```python
import math
print(math.pi)
```

## Exercice

1. Pourquoi `PI = 3.14` est meilleure qu'écrire `3.14` partout dans le code ?
2. Écris une constante `TAUX_TVQ = 0.15` et utilise-la pour calculer un prix total.

## À retenir

- En Python, une constante est une convention, pas un mot-clé.
- Les constantes sont synonymes de **variables de programme** et ont généralement une grande portée (globale).
- Les constantes sont écrites en `MAJUSCULES_AVEC_DES_SOULIGNES`.
- Une constante améliore la lisibilité et la maintenance du code.
- `math.pi` est un exemple courant d'une constante fournie par la bibliothèque standard (même si son nom est en minuscules!).
