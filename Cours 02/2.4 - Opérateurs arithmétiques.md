# Les opérateurs arithmétiques en Python

## Objectifs

- Connaître les opérateurs arithmétiques de base en Python.
- Comprendre la différence entre division réelle et division entière.
- Savoir utiliser l'affectation composée pour incrémenter ou décrémenter.

Python propose sept opérateurs arithmétiques de base :

|Opérateur|Nom|Description|Exemple (`a = 10`, `b = 3`)|
|:---:|---|---|---|
|`+`|Addition|Additionne deux valeurs|`a + b` → `13`|
|`-`|Soustraction|Soustrait la seconde valeur de la première|`a - b` → `7`|
|`*`|Multiplication|Multiplie deux valeurs|`a * b` → `30`|
|`**`|Puissance|Applique une exposant à une base|`a ** b` → `1000` = `10^3`|
|`/`|Division réelle|Donne **toujours** le quotient exact, même entre 2 entiers|`a / b` → `3.3333333333333335`|
|`//`|Division entière|Donne la division entière (tronque la partie décimale)|`a // b` → `3`|
|`%`|Modulo|Reste de la division|`a % b` → `1`|

## ⚠️ Le comportement de la division `/`

**En Python, `/` fait toujours une division réelle**, peu importe les types des opérandes, et retourne toujours un `float` :

```python
a = 10
b = 3
print(a / b)   # 3.3333333333333335 — même si a et b sont des entiers!
```

Pour obtenir une division entière, Python utilise un opérateur **dédié et distinct : `//`** :

```python
print(a // b)  # 3 — division entière, la partie décimale est tronquée
```

## ⚠️ Pas d'opérateurs `++` ni `--`

**Python n'a pas d'opérateurs d'incrémentation (`++`) ou de décrémentation (`--`)**, ni en version préfixe ni en version postfixe. Pour ajouter ou retirer `1` à une variable, il faut utiliser l'opérateur d'assignation composée `+=` ou `-=` :

```python
a = 10
a += 1   # ajoute 1 à la variable a
a -= 1   # retire 1 à la variable a
```

## Remarques importantes

- La division `/` retourne **toujours** un `float` en Python, quel que soit le type des opérandes.
- La division entière `//` tronque toujours vers le bas (vers l'infini négatif) lorsque les nombres sont négatifs.
- Le modulo `%` est utile pour vérifier la **parité** (pair/impair) ou pour des opérations cycliques.
- Le modulo `%` impliquant des nombres à virgule flottante ne sera pas étudié dans ce cours.

## Priorité des opérations

> **Référence** : [La priorité des opérateurs](https://docs.python.org/fr/3.14/reference/expressions.html#operator-precedence)

Voici un résumé simplifié des priorités les plus importantes (de la plus forte à la plus faible) :

1. Parenthèses `()`
2. Puissance `**`
3. Opérateurs unaires `+x`, `-x`
4. Multiplication, division, modulo `*`, `/`, `//`, `%`
5. Addition et soustraction `+`, `-`
6. Comparaisons `<`, `>`, `<=`, `>=`, `==`, `!=`
7. NON logique `not`
8. ET logique `and`
9. OU logque `or`
10. Conditionnelles `if / elif / else`
11. Affectations `=`, `+=`, `-=`, `*=`, `/=`, `%=`

## Exemple : calcul simple

```python
a = 10
b = 3
print(f"Addition : {a + b}")
print(f"Soustraction : {a - b}")
print(f"Multiplication : {a * b}")
print(f"Puissance : {a ** b}")
print(f"Division réelle : {a / b}")
print(f"Division entière : {a // b}")
print(f"Modulo : {a % b}")
```

## Exemple - Roche Papier Ciseaux - Optimisation via modulo

Voici un exemple de code Python pour résoudre le jeu Roche-Papier-Ciseaux en utilisant le modulo pour déterminer le gagnant :

```python
import random  # voir https://docs.python.org/3/library/random.html

choix = ["Roche", "Papier", "Ciseaux"]

print("Choisissez : 0 = Roche, 1 = Papier, 2 = Ciseaux")
joueur = 2  # votre choix, à modifier
ordinateur = random.randint(0, 2)  # valeur aléatoire entre 0 et 2 inclusivement

print(f"Vous avez choisi : {choix[joueur]}")
print(f"L'ordinateur a choisi : {choix[ordinateur]}")

resultat = (joueur - ordinateur + 3) % 3

if resultat == 0:
    print("Égalité !")
elif resultat == 1:
    print("Vous gagnez !")
else:
    print("L'ordinateur gagne !")
```

### Explication du calcul

`(joueur - ordinateur + 3) % 3` permet d'éviter les résultats négatifs.

Résultat :

- 0 → Égalité
- 1 → Le joueur gagne
- 2 → L'ordinateur gagne

*Remarque : `random.randint(0, 2)` inclut les deux bornes (0, 1 et 2 sont tous possibles) — fais attention à toujours vérifier la documentation d'une fonction aléatoire pour savoir si les bornes sont incluses ou exclues.*

## À retenir

- `+`, `-`, `*`, `/`, `//` et `%` sont les opérateurs arithmétiques de base.
- `/` donne toujours un `float` et effectue une division réelle.
- `//` donne la partie entière en tronquant la fraction.
- `%` donne le reste de la division et est utile pour la parité et les calculs cycliques.
- `+=` et `-=` permettent d'ajouter ou de soustraire une valeur en place.
