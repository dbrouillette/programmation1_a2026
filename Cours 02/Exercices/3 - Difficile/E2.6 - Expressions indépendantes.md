# Exercices supplémentaires : Expressions Arithmétiques en Python (2)

Voici encore 10 expressions arithmétiques avancées en Python, mêlant les opérateurs `+`, `-`, `*`, `/`, `//`, `%`, `+=`, `-=`, `*=`, `/=`, `%=` et des groupements entre parenthèses `( )`. Identifiez le résultat ou expliquez le fonctionnement de chaque expression.

**Cette fois, chaque exercice est indépendant** : les variables de chaque exercice repartent de zéro, alors vous pouvez les faire dans n'importe quel ordre.

La difficulté augmente graduellement d'un niveau à l'autre.

## Niveau 1 – Avancé

### Exercice 1

```python
a = 12
b = 5
c = 4
resultat = a + b * 2 - c // 2
```

### Exercice 2

```python
x = 30
x -= (4 + 2) * 3
```

### Exercice 3

```python
c = 17
d = 4
resultat = c // d + c % d
```

### Exercice 4

```python
y = 9
y *= y - (2 + 3)
```

## Niveau 2 – Complexe

### Exercice 5

```python
z = 15
w = 4
resultat = z / w - 1
```

### Exercice 6

```python
p = 6
q = 3
p += q * 2
p *= q - 1
```

### Exercice 7

```python
m = 23
n = 5
o = 3
resultat = (m // n + m % n) * o - n
```

## Niveau 3 – Expert

### Exercice 8

```python
r = 58
s = 7
t = 3
r %= (s + t) * 2 - s
```

### Exercice 9

```python
u = -17
v = 5
resultat = u // v + u % v * 2 - (v - 3)
```

### Exercice 10

```python
k = 40
l = 6
k -= l * 2
k /= 4
k *= (l - 2)
resultat = k + l // 2 - l % 2
```
