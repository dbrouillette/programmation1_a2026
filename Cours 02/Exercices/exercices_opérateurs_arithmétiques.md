# Exercices sur les opérations arithmétiques

Pour chaque opération, prédire l'affichage de la valeur choisie.

*Note : puisque Python n'a pas d'opérateurs `++` / `--` (voir le fichier sur les opérateurs arithmétiques), ces exercices mettent plutôt l'accent sur des particularités propres à Python (comme `**` et `//`).*

## Niveau 1 – Simple

### Exercice 1 a)

```python
a = 5
a += 3
print(f"a = {a}")
# a = __________
```

### Exercice 1 b)

```python
b = 10
b /= 3
print(f"b = {b}")
# b = __________
```

## Niveau 2 – Intermédiaire

### Exercice 2 a)

```python
x = 4
y = 2
z = x * y + 3
print(f"z = {z}")
# z = __________
```

### Exercice 2 b)

```python
c = 15
d = 4
c %= d
print(f"c = {c}")
# c = __________
```

## Niveau 3 – Avancé

### Exercice 3 a)

```python
e = 6
f = 3
g = 2
result1 = e + f * g - 4
print(f"result1 = {result1}")
# result1 = __________
```

### Exercice 3 b)

```python
h = 10
h *= 2
h -= 5
h //= 3
print(f"h = {h}")
# h = __________
```

## Niveau 4 – Complexe

### Exercice 4 a)

```python
i = 2
j = 3
k = 4
l = i ** j + k // 2
print(f"l = {l}")
# l = __________
```

### Exercice 4 b)

```python
m = 12
n = 5
o = 3
m %= n + o
print(f"m = {m}")
# m = __________
```

## Niveau 5 – Expert

### Exercice 5 a)

```python
p = 5
q = 2
r = 15
s = 4
resultat = (p ** q) + (r // s) - (r % s)
print(f"resultat = {resultat}")
# resultat = __________
```
