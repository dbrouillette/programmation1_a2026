# Opérateurs d'affectation combinée

## Objectifs

- Comprendre le rôle des opérateurs d'affectation combinée (`+=`, `-=`, etc.).
- Savoir qu'ils équivalent à une opération suivie d'une affectation.
- Connaître le piège de `/=` et l'absence de `++`/`--` en Python.

En Python, il existe des opérateurs qui sont appelés **opérateurs d'affectation combinée** (compound assignment operators en anglais) et qui combinent une opération arithmétique avec une affectation. Ils sont utilisés pour raccourcir des expressions :

```python
x = 5
x = x + 2
print(x)  # va afficher 7
```

```python
x = 5
x += 2  # équivaut à x = x + 2
print(x)  # va afficher 7
```

## Liste des opérateurs d'affectation combinée

|Opérateur|Rôle|Exemple|Équivalence|Valeur (si `x = 5`)|
|:---:|---|---|---|:---:|
|`+=`|Ajoute la valeur de l'opérande de droite à l'opérande de gauche, puis assigne le résultat.|`x += 3`|`x = x + 3`|`8`|
|`-=`|Enlève la valeur de l'opérande de droite à l'opérande de gauche, puis assigne le résultat.|`x -= 3`|`x = x - 3`|`2`|
|`*=`|Multiplie l'opérande de gauche par la valeur de l'opérande de droite, puis assigne le résultat.|`x *= 3`|`x = x * 3`|`15`|
|`**=`|Élève l'opérande de gauche à la puissance de l'opérande de droite, puis assigne le résultat.|`x **= 3`|`x = x ** 3`|`125`|
|`/=`|Divise l'opérande de gauche par la valeur de l'opérande de droite (division **réelle**), puis assigne le résultat.|`x /= 3`|`x = x / 3`|`1.6666666666666667`|
|`//=`|Divise l'opérande de gauche par la valeur de l'opérande de droite (division **entière**), puis assigne le résultat.|`x //= 3`|`x = x // 3`|`1`|
|`%=`|Calcule le reste après division de l'opérande de gauche par la valeur de l'opérande de droite, puis assigne le résultat.|`x %= 3`|`x = x % 3`|`2`|

## ⚠️ Attention à la ligne `/=`

Remarquez bien la ligne `/=` : comme `/` fait toujours une division réelle en Python (voir la fiche sur [les opérateurs arithmétiques](./2.4%20-%20Opérateurs%20arithmétiques.md)), `x /= 3` avec `x = 5` donne `1.6666666666666667`, et non `1`. Pour obtenir `1`, il faut utiliser `//=`.
