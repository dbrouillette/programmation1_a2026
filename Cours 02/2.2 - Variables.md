# Variables en Python

## Objectifs

- Comprendre comment créer et utiliser une variable en Python.
- Connaître la différence entre déclaration et affectation.
- Savoir respecter les règles de nommage.
- Connaître la convention `snake_case`.
- Comprendre le typage dynamique.

## Déclaration, initialisation, affectation

Python n'a pas d'étape de **déclaration** séparée : une variable est créée au moment même où on lui donne une valeur pour la première fois. Il n'y a donc pas de type à préciser explicitement.

Pour changer la valeur d'une variable, on utilise le symbole d'**affectation** `=`.

```python
nb_etudiants = 22                 # création ET affectation (initialisation), en une seule ligne
cote_cours_prog = 'A'             # une chaîne d'un seul caractère (pas de type char séparé en Python)
msg_succes = "Opération réussie"  # On peut aussi utiliser les "" pour les chaînes, c'est équivalent aux ''
nb_etudiants = 25                 # réaffectation : la variable existait déjà
```

**Il n'est pas possible de « déclarer sans initialiser » en Python.** Une variable n'existe tout simplement pas tant qu'elle n'a pas reçu de valeur.

## Nomenclature des variables

1. Utiliser le `snake_case` : tous les mots en minuscules, séparés par un caractère de soulignement `_`. Seuls les lettres, les chiffres et le `_` sont acceptés.
2. Utiliser des noms explicites et significatifs.
3. Commencer par une lettre ou un `_` (jamais par un chiffre).
4. Ne pas utiliser de mots réservés du langage Python (`class`, `for`, `if`, etc.).

*Voir l'exercice sur les noms de variables.*

## Types en Python

### Typage dynamique

Python utilise un **typage dynamique** : une variable peut changer de type au cours de son existence, simplement en lui affectant une nouvelle valeur d'un autre type — le type n'est jamais fixé de façon permanente.

```python
x = 5        # x contient un entier
x = "cinq"   # maintenant x contient une chaîne de caractères — tout à fait légal!
```

Ce n'est **pas une bonne pratique** de changer le type d'une même variable ainsi (ça rend le code confus), mais il est important de comprendre que Python ne l'empêche pas.

### Types numériques

**Python n'a qu'un seul type entier : `int`**. Sa taille s'ajuste automatiquement selon la grandeur du nombre — il n'y a pas de limite fixe (pas de dépassement de capacité possible).

Pour les nombres à virgule flottante, Python n'a également qu'**un seul type : `float`**, toujours en double précision.

| Type Python | Intervalle |
| --- | --- |
| `int` | Illimité (la seule limite est la mémoire disponible) |
| `float` | ≈ ±1.8 × 10^308 (précision ~15-17 chiffres) |

### Autres types de base

- `str`
  - Pour représenter du texte
  - Python n'a **pas** de type dédié à un seul caractère (comme le type `char` en Java, par exemple)
  - Un seul caractère est simplement une chaîne de caractères (`str`) de longueur 1.
  - Il n'est donc **pas** possible de faire des opérations arithmétiques directement sur un caractère.
- `bool`
  - Le type `bool` ne peut prendre que les valeurs vraies (`True`) ou fausses (`False`) — **notez la majuscule**.
  - Il est principalement utilisé pour :
    - les conditions (`if`, `while`, etc.)
    - les expressions logiques

### Chaînes de caractères

En Python, les chaînes de caractères utilisent le type `str`.

- `str` est un type intégré au langage lui-même.
- Elle représente une séquence de caractères.
- Python accepte indifféremment les guillemets simples (`'`) ou doubles (`"`) pour une chaîne.
- Les objets `str` sont **immuables** :
  - Une fois créées, leur contenu ne peut pas être modifié.
  - Toute opération qui semble modifier une chaîne crée en réalité une nouvelle chaîne.

### La fonction native `type()`

Pour déterminer le type de donnée que représente une variable, on utilise la fonction `type(nom_variable)` à laquelle on "passe la variable" entre parenthèses.

Le résultat sera de la forme `<class 'TYPE'>`, où `TYPE` sera `str`, `int`, `float`, `bool`, etc.

```python
A = 'Salut mon ami!'
B = "Bonjour le monde."
C = ' '
x = 5
y = 2.71
z = True
print(type(A))  # <class 'str'>
print(type(B))  # <class 'str'>
print(type(C))  # <class 'str'>
print(type(x))  # <class 'int'>
print(type(y))  # <class 'float'>
print(type(z))  # <class 'bool'>
```

## Exemples d'initialisations avec les divers types

```python
nombre_enfants = 3
annee = 2025
total = 150000
population = 8142000000   # aucun suffixe nécessaire pour un grand nombre entier
prix = 18.95              # un seul type float pour les nombres à virgule
distance = 6.34575e3      # notation scientifique, vaut 6.34575 * 10^3 = 6345.75
tolerance = 1E-4          # e ou E fonctionnent, vaut 0.0001
caractere = 'a'           # une chaîne de longueur 1 — pas de type char séparé
caractere_unicode = 'M'   # guillemets simples ou doubles, aucune différence en Python
est_vivant = True         # notez la majuscule (True, pas true)
prenom = "Maxime"         # guillemets simples ou doubles acceptés pour une chaîne
```

## Exemple pratique

Comparer la sortie des 2 appels à `print()` suivants. Que pouvez-vous en déduire?

```python
nom = "Emma"
age = 18
# print() peut accepter plusieurs arguments entre les ( )
print("Bonjour", nom, ", tu as", age, "ans")

# Chaîne formatée, ou « f-string »
message = f"Bonjour {nom}, tu as {age} ans."
print(message)
```

**Remarque** : Les chaînes formatées (*f-strings*) seront vues plus en détails ultérieurement dans le cours.

## À retenir

- Une variable est créée lors de sa première affectation.
- Il n'est pas nécessaire de déclarer le type avant d'assigner une valeur.
- Le `snake_case` est la convention de nommage recommandée en Python.
- Le typage dynamique permet de réassigner une variable à un autre type, mais ce n'est pas une bonne pratique lorsque cela rend le code confus.
- La fonction `type()` permet de connaître le type d'une variable.
- Le type `str` est le celui des chaînes de caractères : celles-ci sont **immuables**. C'est-à-dire que si une variable de type `str` est réaffectée, celle-ci est en réalité supprimée et une nouvelle variable `str` est créée avec la nouvelle valeur.
