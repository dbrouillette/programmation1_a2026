# Écrire dans un fichier texte

## Objectifs

- Créer ou remplacer un fichier avec le mode `"w"`.
- Ajouter des lignes à la fin d'un fichier avec le mode `"a"`.
- Écrire avec `write()` sans oublier les retours de ligne.
- Écrire avec `print(..., file=...)`.

> 📋 **Prérequis** : [8.1 - Ouvrir un fichier avec `with`](8.1%20-%20Ouvrir%20un%20fichier%20avec%20with.md).

## 1. Principe

Écrire dans un fichier ressemble beaucoup à la lecture : on ouvre le fichier avec `with`, mais dans un mode d'**écriture**.

```python
with open("message.txt", "w", encoding="utf-8") as fichier:
    fichier.write("Bienvenue au Café Le Binaire!\n")
```

Après l'exécution, le fichier `message.txt` existe dans le dossier courant (voir [8.5](8.5%20-%20Sauvegarder%20et%20recharger%20une%20liste.md)) et contient une ligne.

## 2. Le mode `"w"` : créer ou remplacer

Le mode `"w"` (*write*) :

- **crée** le fichier s'il n'existe pas;
- **efface tout son contenu** s'il existe déjà, avant d'écrire.

```python
with open("message.txt", "w", encoding="utf-8") as fichier:
    fichier.write("Première version\n")

with open("message.txt", "w", encoding="utf-8") as fichier:
    fichier.write("Deuxième version\n")
```

Le fichier ne contient plus que `Deuxième version` : la première ligne a été écrasée.

> ⚠️ Ouvrir un fichier en mode `"w"` l'efface **immédiatement**, même si on n'écrit rien ensuite. On ne l'utilise que si on veut réécrire le fichier au complet.

## 3. `write()` n'ajoute pas de retour de ligne

Contrairement à `print()`, la méthode `write()` écrit **exactement** la chaîne reçue, sans rien ajouter.

```python
# ❌ Mauvais : tout se retrouve sur une seule ligne
with open("menu.txt", "w", encoding="utf-8") as fichier:
    fichier.write("Café filtre")
    fichier.write("Latté")
    fichier.write("Muffin")
```

```text
Café filtreLattéMuffin
```

```python
# ✅ Bon : chaque ligne se termine par \n
with open("menu.txt", "w", encoding="utf-8") as fichier:
    fichier.write("Café filtre\n")
    fichier.write("Latté\n")
    fichier.write("Muffin\n")
```

```text
Café filtre
Latté
Muffin
```

`write()` n'accepte que des **chaînes**. Pour écrire un nombre, on le convertit, idéalement avec une f-string :

```python
total = 48.85

# ❌ Mauvais : TypeError: write() argument must be str, not float
fichier.write(total)

# ✅ Bon
fichier.write(f"{total:.2f}\n")
```

## 4. Écrire avec `print(..., file=...)`

On peut aussi utiliser `print()` en lui indiquant d'écrire dans le fichier plutôt qu'à l'écran. `print()` ajoute le `\n` et convertit les nombres lui-même :

```python
with open("menu.txt", "w", encoding="utf-8") as fichier:
    print("Café filtre", file=fichier)
    print("Latté", file=fichier)
    print("Total :", 48.85, file=fichier)
```

> 💡 `write()` et `print(file=...)` donnent le même résultat. `write()` est plus courant dans le code professionnel, mais `print(file=...)` est pratique pour éviter d'oublier un `\n`. Choisis-en un et reste constant.

## 5. Le mode `"a"` : ajouter à la fin

Le mode `"a"` (*append*) écrit **à la suite** du contenu existant, sans rien effacer. C'est le mode idéal pour un **journal** (*log*) ou un historique.

```python
def enregistrer_vente(montant):
    with open("historique.txt", "a", encoding="utf-8") as fichier:
        fichier.write(f"{montant:.2f}\n")

enregistrer_vente(12.50)
enregistrer_vente(8.75)
```

Chaque exécution du programme **ajoute** des lignes à `historique.txt`. Si le fichier n'existe pas, il est créé.

| Je veux… | Mode |
| --- | --- |
| Lire un fichier | `"r"` |
| Réécrire un fichier au complet (sauvegarde) | `"w"` |
| Ajouter une ligne à un historique | `"a"` |

## 6. Pièges fréquents

| Piège | Symptôme | Correction |
| --- | --- | --- |
| Oublier `\n` avec `write()` | Tout est sur une ligne | Terminer chaque chaîne par `\n` |
| Ouvrir en `"w"` pour lire | Le fichier est vidé! | Utiliser `"r"` pour lire |
| Écrire un nombre avec `write()` | `TypeError` | Convertir : `f"{nombre}\n"` |
| Oublier `encoding="utf-8"` | Accents illisibles (`Ã©`) | Toujours préciser l'encodage |
| Fichier ouvert dans Excel ou un autre logiciel | `PermissionError` (Windows) | Fermer le fichier dans l'autre logiciel |

## En résumé

- Le mode `"w"` crée le fichier ou **efface** son contenu avant d'écrire.
- Le mode `"a"` ajoute à la fin du fichier sans rien effacer.
- `fichier.write(chaine)` écrit exactement la chaîne : il faut ajouter `\n` soi-même et convertir les nombres.
- `print(valeur, file=fichier)` écrit dans le fichier avec un retour de ligne automatique.
