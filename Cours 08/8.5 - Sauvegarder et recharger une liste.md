# Sauvegarder et recharger une liste

## Objectifs

- Comprendre où Python cherche un fichier (le **dossier courant**).
- Construire un chemin fiable avec `Path(__file__).parent`.
- Sauvegarder une liste dans un fichier, puis la recharger au démarrage suivant.
- Appliquer le patron `charger_...()` / `sauvegarder_...()`.

> 📋 **Prérequis** : [8.3 - Lire un fichier texte](8.3%20-%20Lire%20un%20fichier%20texte.md) et [8.4 - Écrire dans un fichier texte](8.4%20-%20Écrire%20dans%20un%20fichier%20texte.md).

## 1. Où Python cherche-t-il le fichier?

Un chemin comme `"menu.txt"` est un **chemin relatif** : Python le cherche dans le **dossier courant** (*current working directory*), c'est-à-dire le dossier **depuis lequel le programme est lancé**… qui n'est pas toujours celui du fichier `.py`!

C'est le piège classique dans VS Code : si tu as ouvert le dossier `programmation1_a2026` au complet et que ton programme est dans `Cours 08/Exemples`, le dossier courant est souvent `programmation1_a2026`. Résultat : `FileNotFoundError`, alors que `menu.txt` est juste à côté du programme.

### La solution : partir du dossier du programme

Le module `pathlib` permet de construire un chemin à partir du dossier qui contient le fichier `.py` :

```python
from pathlib import Path

DOSSIER = Path(__file__).parent          # dossier qui contient ce programme
CHEMIN_MENU = DOSSIER / "menu.txt"       # l'opérateur / assemble les morceaux du chemin

with open(CHEMIN_MENU, "r", encoding="utf-8") as fichier:
    contenu = fichier.read()
```

- `__file__` est une variable spéciale qui contient le chemin du programme en cours d'exécution.
- `.parent` donne le dossier qui le contient.
- L'opérateur `/` assemble un dossier et un nom de fichier, avec le bon séparateur (`\` sous Windows, `/` sous macOS et Linux).

> 📌 **Règle pratique** : dans un programme qui sera remis ou partagé, on construit les chemins avec `Path(__file__).parent`. Le programme fonctionne alors peu importe d'où il est lancé.

### Chemins absolus

Un **chemin absolu** part de la racine du disque, par exemple `C:\Users\david\Documents\menu.txt`. On l'évite dans un programme : il ne fonctionnera pas sur l'ordinateur de quelqu'un d'autre.

> ⚠️ Si tu dois quand même écrire un chemin Windows dans une chaîne, attention aux `\` : `"C:\nouveau"` contient un `\n` (retour de ligne)! Utilise plutôt des `/`, que Windows accepte aussi : `"C:/Users/david/menu.txt"`.

## 2. Sauvegarder et relire une liste

Le cas le plus courant : le programme garde ses données dans une **liste** pendant qu'il roule, la **sauvegarde** dans un fichier à la fin, puis la **recharge** au prochain démarrage.

```python
from pathlib import Path

CHEMIN_TACHES = Path(__file__).parent / "taches.txt"

def sauvegarder_taches(taches):
    """Écrit une tâche par ligne. Le fichier est remplacé au complet."""
    with open(CHEMIN_TACHES, "w", encoding="utf-8") as fichier:
        for tache in taches:
            fichier.write(f"{tache}\n")

def charger_taches():
    """Renvoie la liste des tâches, ou une liste vide si le fichier n'existe pas encore."""
    taches = []
    try:
        with open(CHEMIN_TACHES, "r", encoding="utf-8") as fichier:
            for ligne in fichier:
                tache = ligne.strip()
                if tache != "":
                    taches.append(tache)
    except FileNotFoundError:
        pass    # première exécution : aucune tâche, ce n'est pas une erreur
    return taches

def main():
    taches = charger_taches()
    print(f"{len(taches)} tâche(s) en mémoire : {taches}")

    nouvelle = input("Nouvelle tâche (Entrée pour terminer) : ").strip()
    while nouvelle != "":
        taches.append(nouvelle)
        nouvelle = input("Nouvelle tâche (Entrée pour terminer) : ").strip()

    sauvegarder_taches(taches)
    print("Tâches sauvegardées.")

main()
```

Première exécution :

```text
0 tâche(s) en mémoire : []
Nouvelle tâche (Entrée pour terminer) : Commander du lait
Nouvelle tâche (Entrée pour terminer) : Laver la machine à espresso
Nouvelle tâche (Entrée pour terminer) :
Tâches sauvegardées.
```

Deuxième exécution :

```text
2 tâche(s) en mémoire : ['Commander du lait', 'Laver la machine à espresso']
Nouvelle tâche (Entrée pour terminer) :
Tâches sauvegardées.
```

> 💡 L'instruction `pass` ne fait rien. On l'utilise quand Python exige un bloc, mais qu'il n'y a rien à faire : ici, un fichier absent signifie simplement qu'il n'y a pas encore de tâches.
>
> 📌 **Le duo `charger_...()` / `sauvegarder_...()`** est le patron à retenir pour ce cours et pour le TP : on charge au démarrage, on travaille en mémoire avec des listes, on sauvegarde à la fin (ou après chaque modification).

## En résumé

- Un chemin relatif (`"menu.txt"`) est cherché dans le **dossier courant**, qui n'est pas toujours celui du programme.
- `Path(__file__).parent / "fichier.txt"` construit un chemin fiable vers un fichier placé à côté du programme.
- On évite les chemins absolus : ils ne fonctionnent pas sur un autre ordinateur.
- Pour conserver une liste : `sauvegarder_...()` l'écrit en mode `"w"`, `charger_...()` la relit au démarrage.
- Un fichier absent au premier démarrage n'est pas une erreur : on commence avec une liste vide.
