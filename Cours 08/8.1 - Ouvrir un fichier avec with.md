# Ouvrir un fichier avec `with`

## Objectifs

- Comprendre pourquoi un programme a besoin de fichiers.
- Ouvrir un fichier avec `with open()` et comprendre chaque morceau de l'instruction.
- Choisir le bon **mode** d'ouverture : `"r"`, `"w"` ou `"a"`.
- Comprendre pourquoi `with` referme le fichier pour nous.

> ⚠️ **Python Tutor ne gère pas les fichiers.** Les exemples de ce cours doivent être exécutés dans VS Code. Crée les fichiers texte (`.txt`, `.csv`) dans le **même dossier** que ton programme.

## 1. Principe

Jusqu'ici, toutes les données de nos programmes vivaient dans des **variables**, donc dans la mémoire vive (RAM). Dès que le programme se termine, tout disparaît : la commande du client, le score du joueur, la liste d'épicerie…

Un **fichier**, quant à lui, peut être stocké sur le disque. Il survit à la fermeture du programme et même à l'arrêt de l'ordinateur. On s'en sert pour :

- **lire** des données préparées à l'avance (un menu, une liste de questions, une chanson);
- **sauvegarder** des résultats (un historique de ventes, un tableau des meilleurs scores);
- **mémoriser** les préférences de l'utilisateur d'une exécution à l'autre (nous le verrons au cours 9).

Travailler avec un fichier se fait toujours en trois étapes :

1. **Ouvrir** le fichier;
2. **Lire** ou **écrire**;
3. **Fermer** le fichier.

En Python, on n'a pas à s'occuper de l'étape 3 : l'instruction `with` ferme le fichier **automatiquement**.

## 2. Ouvrir un fichier : `with open()`

```python
with open("menu.txt", "r", encoding="utf-8") as fichier:
    contenu = fichier.read()

print(contenu)
```

Lisons la première ligne morceau par morceau :

| Morceau | Rôle |
| --- | --- |
| `with` | « Avec ce fichier ouvert, fais ce qui suit… puis referme-le. » |
| `open("menu.txt", "r", encoding="utf-8")` | Ouvre le fichier |
| `as fichier` | Donne le nom `fichier` au fichier ouvert, pour l'utiliser dans le bloc |
| `:` et le bloc indenté | Le travail à faire **pendant** que le fichier est ouvert |

Dès que le bloc indenté se termine, le fichier est fermé. La variable `contenu`, elle, existe toujours : on peut l'afficher après le bloc.

La fonction `open()` reçoit trois informations :

| Argument | Rôle | Exemple |
| --- | --- | --- |
| Le **chemin** du fichier | Où trouver le fichier | `"menu.txt"` |
| Le **mode** | Ce qu'on veut faire avec le fichier | `"r"` pour lire |
| L'**encodage** | Comment les caractères sont codés en octets | `encoding="utf-8"` |

### Les modes d'ouverture

| Mode | Signification | Si le fichier n'existe pas | Si le fichier existe |
| --- | --- | --- | --- |
| `"r"` | *read* : lecture (mode par défaut) | ❌ `FileNotFoundError` | On lit son contenu |
| `"w"` | *write* : écriture | Il est créé | ⚠️ Son contenu est **effacé** |
| `"a"` | *append* : ajout à la fin | Il est créé | On écrit à la suite |

Les modes `"w"` et `"a"` sont présentés en [8.4](8.4%20-%20Écrire%20dans%20un%20fichier%20texte.md). L'encodage a sa propre fiche : [8.2 - L'encodage des caractères](8.2%20-%20L'encodage%20des%20caractères.md).

## 3. Pourquoi `with`?

Un fichier ouvert doit **toujours** être refermé. Sinon, il reste verrouillé (Windows refuse alors de le modifier ou de le supprimer), et des données écrites peuvent même être perdues.

`with` s'en charge pour nous : le fichier est fermé à la fin du bloc indenté, **même si une erreur survient** pendant la lecture. On ne peut donc jamais oublier de le fermer.

### Le piège : utiliser le fichier après le bloc

Une fois sorti du bloc, le fichier est fermé : on ne peut plus le lire.

```python
with open("menu.txt", "r", encoding="utf-8") as fichier:
    contenu = fichier.read()

# ❌ Mauvais : le fichier est déjà fermé
ligne = fichier.readline()
```

```text
ValueError: I/O operation on closed file.
```

On fait donc **tout** le travail sur le fichier dans le bloc indenté, et on garde ce qu'on a lu dans une variable (`contenu`) pour la suite du programme.

> 📌 **Règle pratique** : dans ce cours, on ouvre **toujours** un fichier avec `with`.

## En résumé

- Un fichier conserve les données **après** la fin du programme.
- On ouvre un fichier avec `with open(chemin, mode, encoding="utf-8") as fichier:`.
- Le mode `"r"` sert à lire (c'est le mode par défaut), `"w"` à réécrire, `"a"` à ajouter.
- Le fichier est fermé automatiquement à la fin du bloc indenté, même en cas d'erreur.
- Tout le travail sur le fichier se fait dans le bloc; après le bloc, le fichier est fermé.
