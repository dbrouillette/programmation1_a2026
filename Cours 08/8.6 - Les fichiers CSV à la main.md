# Les fichiers CSV à la main

## Objectifs

- Comprendre le format CSV et pourquoi il est si répandu.
- Lire un fichier CSV **sans aucune librairie**, avec `split()`.
- Convertir les champs lus dans le bon type.
- Charger un fichier CSV dans une liste 2D.
- Écrire un fichier CSV avec `join()`.
- Connaître les limites de l'approche « à la main ».

> 📋 **Prérequis** : [8.3 - Lire un fichier texte](8.3%20-%20Lire%20un%20fichier%20texte.md) et [8.4 - Écrire dans un fichier texte](8.4%20-%20Écrire%20dans%20un%20fichier%20texte.md).

## 1. Le format CSV

Un fichier **CSV** (*Comma-Separated Values*, valeurs séparées par des virgules) est un simple fichier texte qui représente un **tableau** :

- chaque **ligne** du fichier est une **rangée** du tableau;
- dans une ligne, les **colonnes** sont séparées par un **délimiteur**, habituellement la virgule;
- la première ligne contient souvent les **noms des colonnes** : c'est l'**en-tête**.

Fichier `menu.csv` :

```text
produit,categorie,prix,stock
Café filtre,boisson,2.25,40
Latté,boisson,4.50,25
Chocolat chaud,boisson,3.75,15
Muffin,patisserie,3.25,12
Biscuit,patisserie,1.95,30
```

Ce même fichier, ouvert dans Excel, ressemble à ceci :

| produit | categorie | prix | stock |
| --- | --- | --- | --- |
| Café filtre | boisson | 2.25 | 40 |
| Latté | boisson | 4.50 | 25 |
| Chocolat chaud | boisson | 3.75 | 15 |
| Muffin | patisserie | 3.25 | 12 |
| Biscuit | patisserie | 1.95 | 30 |

Le CSV est partout : exportation d'Excel ou de Google Sheets, données ouvertes du gouvernement, relevés bancaires, résultats exportés de Léa ou de Moodle… C'est le format universel pour échanger des tableaux.

> 💡 Un fichier CSV se crée et se modifie directement dans VS Code. L'extension **Rainbow CSV** colore chaque colonne d'une couleur différente, ce qui facilite beaucoup la lecture.

## 2. Découper une ligne : `split()`

La méthode `split()` (voir [6.2 - Les listes](../Cours%2006/6.2%20-%20Les%20listes.md)) découpe une chaîne selon un séparateur et renvoie une **liste** :

```python
ligne = "Latté,boisson,4.50,25\n"

champs = ligne.strip().split(",")
print(champs)
```

```text
['Latté', 'boisson', '4.50', '25']
```

Chaque **champ** est accessible par son index :

```python
produit = champs[0]     # 'Latté'
categorie = champs[1]   # 'boisson'
prix = champs[2]        # '4.50'  ← encore une chaîne!
stock = champs[3]       # '25'    ← encore une chaîne!
```

> ⚠️ Le `strip()` doit être fait **avant** le `split()`. Sinon, le dernier champ contient le `\n` : `'25\n'`.

### Convertir les champs

Comme pour toute lecture de fichier, les champs sont des **chaînes**. On convertit ceux qui représentent des nombres :

```python
produit = champs[0]
categorie = champs[1]
prix = float(champs[2])
stock = int(champs[3])

print(f"{produit} : {prix:.2f} $ ({stock} en stock)")
```

```text
Latté : 4.50 $ (25 en stock)
```

## 3. Lire tout le fichier

On combine la lecture ligne par ligne de [8.3](8.3%20-%20Lire%20un%20fichier%20texte.md) et `split()`. Il faut cependant **sauter l'en-tête**, sinon `float("prix")` provoque une `ValueError`.

### Sauter l'en-tête avec `readline()`

La méthode `readline()` lit **une seule ligne**. Si on l'appelle avant la boucle, la boucle commence à la ligne suivante :

```python
with open("menu.csv", "r", encoding="utf-8") as fichier:
    fichier.readline()                        # on lit l'en-tête et on l'ignore
    for ligne in fichier:
        champs = ligne.strip().split(",")
        produit = champs[0]
        prix = float(champs[2])
        stock = int(champs[3])
        print(f"{produit:<18}{prix:>6.2f} ${stock:>5}")
```

```text
Café filtre         2.25 $   40
Latté               4.50 $   25
Chocolat chaud      3.75 $   15
Muffin              3.25 $   12
Biscuit             1.95 $   30
```

## 4. Charger le CSV dans une liste 2D

Plutôt que d'afficher au fur et à mesure, on range chaque rangée dans une **liste 2D** (voir [6.3](../Cours%2006/6.3%20-%20Les%20boucles%20for%20imbriquées.md)) : une liste qui contient une liste par produit. Le programme peut ensuite chercher, trier, calculer…

```python
def charger_menu(nom_fichier):
    """Renvoie une liste 2D : [[produit, categorie, prix, stock], ...]."""
    menu = []
    with open(nom_fichier, "r", encoding="utf-8") as fichier:
        fichier.readline()                    # en-tête
        for ligne in fichier:
            ligne = ligne.strip()
            if ligne != "":                   # on ignore les lignes vides
                champs = ligne.split(",")
                rangee = [champs[0], champs[1], float(champs[2]), int(champs[3])]
                menu.append(rangee)
    return menu

menu = charger_menu("menu.csv")
print(menu[1])          # ['Latté', 'boisson', 4.5, 25]
print(menu[1][2])       # 4.5

valeur_stock = 0.0
for rangee in menu:
    valeur_stock += rangee[2] * rangee[3]
print(f"Valeur du stock : {valeur_stock:.2f} $")
```

```text
['Latté', 'boisson', 4.5, 25]
4.5
Valeur du stock : 356.25 $
```

> 💡 Pour éviter les « nombres magiques » `rangee[2]` et `rangee[3]`, on peut définir des constantes pour les index des colonnes :
>
> ```python
> COL_PRODUIT = 0
> COL_CATEGORIE = 1
> COL_PRIX = 2
> COL_STOCK = 3
>
> valeur_stock += rangee[COL_PRIX] * rangee[COL_STOCK]
> ```

### Valider les données lues

Un fichier CSV est souvent modifié à la main. Une ligne mal formée (champ manquant, prix illisible) ne doit pas faire planter tout le programme. On applique les principes de [5.3 - La validation de données](../Cours%2005/5.3%20-%20La%20validation%20de%20données.md) :

```python
NB_COLONNES = 4

numero = 1                                    # l'en-tête est la ligne 1
for ligne in fichier:
    numero += 1
    champs = ligne.strip().split(",")
    if len(champs) != NB_COLONNES:
        print(f"Ligne {numero} ignorée : {len(champs)} colonnes au lieu de {NB_COLONNES}.")
    else:
        try:
            rangee = [champs[0], champs[1], float(champs[2]), int(champs[3])]
            menu.append(rangee)
        except ValueError:
            print(f"Ligne {numero} ignorée : prix ou stock invalide.")
```

## 5. Écrire un fichier CSV : `join()`

La méthode `join()` fait l'inverse de `split()` : elle **assemble** les éléments d'une liste en une seule chaîne, avec un séparateur entre chacun.

```python
champs = ["Latté", "boisson", "4.50", "25"]
ligne = ",".join(champs)
print(ligne)            # Latté,boisson,4.50,25
```

> ⚠️ `join()` n'accepte que des **chaînes**. Avec une rangée qui contient des nombres, `",".join(["Latté", "boisson", 4.5, 25])` provoque une `TypeError`. Il faut convertir chaque élément avec `str()`, ou construire la ligne avec une f-string.

```python
def sauvegarder_menu(nom_fichier, menu):
    """Écrit la liste 2D du menu dans un fichier CSV, avec l'en-tête."""
    with open(nom_fichier, "w", encoding="utf-8") as fichier:
        fichier.write("produit,categorie,prix,stock\n")
        for rangee in menu:
            fichier.write(f"{rangee[0]},{rangee[1]},{rangee[2]:.2f},{rangee[3]}\n")

menu = charger_menu("menu.csv")
menu[1][3] -= 2                               # on vend 2 lattés
menu.append(["Thé vert", "boisson", 2.75, 20])  # nouveau produit
sauvegarder_menu("menu.csv", menu)
```

Le cycle complet **charger → modifier en mémoire → sauvegarder** est exactement celui de [8.5](8.5%20-%20Sauvegarder%20et%20recharger%20une%20liste.md), mais avec un tableau au lieu d'une simple liste.

## 6. Les limites de l'approche « à la main »

Notre méthode est **naïve** : elle fonctionne parfaitement tant que les données sont simples. Mais le format CSV réel a des règles que `split(",")` ignore.

### Problème 1 : une virgule dans une valeur

Que se passe-t-il si un produit s'appelle `Muffin, bleuets`?

```text
Muffin, bleuets,patisserie,3.50,8
```

```python
print("Muffin, bleuets,patisserie,3.50,8".split(","))
```

```text
['Muffin', ' bleuets', 'patisserie', '3.50', '8']
```

Cinq champs au lieu de quatre! Pour régler ce cas, la norme CSV entoure la valeur de **guillemets** :

```text
"Muffin, bleuets",patisserie,3.50,8
```

… mais `split(",")` ne connaît pas cette règle et découpe quand même à l'intérieur des guillemets. Gérer correctement les guillemets (et les guillemets **dans** les guillemets, et les retours de ligne dans une valeur…) devient vite compliqué.

### Problème 2 : Excel en français

Au Québec, Excel utilise souvent la **virgule comme séparateur décimal** (`4,50`). Il ne peut donc pas utiliser la virgule comme délimiteur : il exporte ses CSV avec des **points-virgules** :

```text
produit;categorie;prix;stock
Latté;boisson;4,50;25
```

Il faut alors découper avec `split(";")` et remplacer la virgule décimale avant la conversion : `float("4,50".replace(",", "."))`.

### Problème 3 : l'encodage d'Excel

Selon la version, Excel enregistre ses CSV en `cp1252` ou en UTF-8 avec une signature invisible au début du fichier (*BOM*). Avec l'encodage `"utf-8"`, le premier en-tête peut alors s'afficher comme `'﻿produit'`. L'encodage `"utf-8-sig"` règle ce problème : il lit l'UTF-8 normal **et** retire la signature si elle est présente.

> 📌 **Conclusion** : l'approche avec `split()` est excellente pour **comprendre** et pour des fichiers que **tu contrôles** (comme ceux de ton TP). Pour des fichiers qui viennent d'ailleurs, on utilise le module `csv` de Python, qui connaît toutes ces règles. C'est le sujet de la fiche [Module csv](../Outils/Fichiers%20CSV%20-%20Module%20csv.md), dans les outils.

## En résumé

- Un fichier CSV est un fichier texte qui représente un tableau : une rangée par ligne, des colonnes séparées par un délimiteur.
- `ligne.strip().split(",")` transforme une ligne en liste de champs.
- Les champs sont des chaînes : on convertit avec `int()` ou `float()`.
- `fichier.readline()` avant la boucle permet de sauter l'en-tête.
- On charge habituellement un CSV dans une **liste 2D**.
- `",".join(liste_de_chaines)` assemble une ligne CSV; une f-string fonctionne aussi.
- `split()` ne gère ni les guillemets, ni les virgules dans les valeurs : pour des fichiers externes, on utilise le module `csv`.
