# Installation de Python et de l'IDE

## Objectifs d'apprentissage

- Installer Python sur son poste de travail
- Installer et configurer un environnement de développement (IDE)
- Vérifier que l'installation fonctionne correctement
- Écrire, enregistrer et exécuter un premier script Python

## Installer Python

1. Se rendre sur [python.org/downloads](https://www.python.org/downloads/)
2. Télécharger la dernière version stable de Python 3 pour son système d'exploitation
3. **Important (Windows)** : cocher la case *"Add Python to PATH"* lors de l'installation
4. Terminer l'installation en suivant l'assistant

### Vérifier l'installation

Ouvrir un terminal PowerShell (ou l'invite de commandes CMD) et taper :

```bash
python --version
```

ou, selon le système :

```bash
python3 --version
```

On devrait voir s'afficher un numéro de version, par exemple `Python 3.12.4`.

## Installer un environnement de développement (IDE)

Un **EDI** (*Environnement de développement intégré*) est un logiciel qui facilite l'écriture, l'exécution et le débogage du code. Dans ce cours, nous utiliserons **Visual Studio Code (VS Code)**.

1. Télécharger VS Code sur [code.visualstudio.com](https://code.visualstudio.com/)
2. Installer l'extension **Python** (par Microsoft) via l'onglet Extensions
3. Ouvrir un dossier de travail pour le cours

## Écrire et exécuter son premier script

1. Créer un nouveau fichier nommé `hello.py`
2. Écrire le code suivant :

   ```python
   print("Bonjour, monde!")
   ```

3. Exécuter le script :

   - Dans VS Code : bouton ▶ *Run Python File*
   - Ou en ligne de commande, dans le terminal :

      ```bash
      python hello.py
      ```

**Résultat attendu :** on voit le texte suivant affiché à l'écran

```text
Bonjour, monde!
```

## Structure recommandée pour le cours

Il est recommandé de créer un dossier de travail organisé, par exemple :

```text
IntroProgrammation/
├── Semaine01/
│   ├── hello.py
│   └── exercices.py
├── Semaine02/
└── ...
```

## Dépannage courant

| Problème | Cause probable | Solution |
| --- | --- | --- |
| `python : commande introuvable` | Python n'est pas dans le PATH | Réinstaller en cochant "Add to PATH" |
| Erreur d'extension Python dans VS Code | Extension non installée | Installer l'extension Python |
| Le script ne s'exécute pas | Mauvais interpréteur sélectionné | Sélectionner l'interpréteur Python dans VS Code (Ctrl+Shift+P → *Python: Select Interpreter*) |
