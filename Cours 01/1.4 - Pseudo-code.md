# Pseudo-code

## Objectifs d'apprentissage

- Définir le pseudo-code et comprendre son utilité
- Connaître les conventions courantes utilisées en pseudo-code
- Traduire un algorithme exprimé en langage naturel vers un pseudo-code structuré
- Établir des liens entre les instructions de pseudo-code et leur équivalent en Python

## Qu'est-ce que le pseudo-code?

Le **pseudo-code** est une façon d'écrire un algorithme dans un langage semi-formel, à mi-chemin entre le langage naturel (français, anglais) et un vrai langage de programmation. Il permet de se concentrer sur la **logique** de la solution sans se soucier de la syntaxe précise d'un langage donné.

Le pseudo-code n'a pas de norme universelle stricte, mais certaines conventions reviennent souvent.

## Conventions courantes

### Déclaration et affectation de variables

```text
VARIABLE nom ← valeur
```

Exemple :

```text
age ← 25
prenom ← "Maria"
```

### Entrée / sortie

```text
LIRE variable        // demander une valeur à l'utilisateur
ÉCRIRE expression     // afficher un résultat
```

### Structures conditionnelles

```text
SI condition ALORS
    instructions
SINON
    instructions
FIN SI
```

### Structures répétitives

```text
TANT QUE condition FAIRE
    instructions
FIN TANT QUE

POUR variable DE début À fin FAIRE
    instructions
FIN POUR
```

## Exemple complet : moyenne de trois notes

**Pseudo-code :**

```text
DÉBUT
    LIRE note1
    LIRE note2
    LIRE note3
    moyenne ← (note1 + note2 + note3) / 3
    ÉCRIRE moyenne
FIN
```

**Traduction en Python :**

```python
note1 = float(input("Note 1 : "))
note2 = float(input("Note 2 : "))
note3 = float(input("Note 3 : "))

moyenne = (note1 + note2 + note3) / 3

print(moyenne)
```

## Exemple avec une condition

**Pseudo-code :**

```text
DÉBUT
    LIRE note
    SI note >= 60 ALORS
        ÉCRIRE "Réussite"
    SINON
        ÉCRIRE "Échec"
    FIN SI
FIN
```

**Traduction en Python :**

```python
note = float(input("Note : "))

if note >= 60:
    print("Réussite")
else:
    print("Échec")
```

## Pourquoi utiliser le pseudo-code?

- Il permet de **planifier** la logique avant de se battre avec la syntaxe d'un langage
- Il est **indépendant du langage** — un algorithme en pseudo-code peut se traduire en Python, Java, C++, etc.
- Il facilite la **communication** entre programmeurs, peu importe le langage qu'ils maîtrisent
- Il aide à **détecter les erreurs de logique** avant même d'écrire du vrai code
