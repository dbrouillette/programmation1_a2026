# Comment fonctionnent les langages de programmation ?

## Objectifs

- Comprendre les étapes entre l'écriture du code et son exécution par la machine.
- Distinguer un langage compilé d'un langage interprété.
- Savoir où se situe Python dans ce processus.

Comprendre comment un langage de programmation fonctionne, de l'écriture d'une instruction à son exécution sur une machine, implique plusieurs couches de transformation et d'interprétation. Voici une vue d'ensemble du processus :

## 🧠 1. Écriture du code source

Tu écris des instructions dans un langage de programmation comme Python, C++, etc. Ce langage est compréhensible par les humains, mais pas directement par la machine.

Exemple en Python (le langage que nous utiliserons dans ce cours) :

```python
print("Bonjour le monde!")
```

## 🛠️ 2. Traduction du code (Compilation ou Interprétation)

Il existe deux grandes **familles** de langages :

- **Langages compilés** (ex. C, C++) :
  - Le code source est traduit en langage machine (binaire) par un compilateur.
  - Le résultat est un fichier exécutable (`.exe`, `.bat`, `.msi`, etc.).
  - Ce fichier peut être lancé directement par le système d'exploitation.

- **Langages interprétés** (ex. Python, JavaScript) :
  - Le code est **lu ligne par ligne** par un **interpréteur**.
  - Chaque instruction est traduite et exécutée **à la volée**.
  - Python est de cette famille : il n'y a pas d'étape de compilation séparée à lancer soi-même.

Certains langages utilisent une **approche hybride** :

- Le code source est d'abord compilé en ***bytecode***.
- Ce *bytecode* est ensuite exécuté (interprété) par une **machine virtuelle**.

*Fait intéressant : Python fait en réalité un peu la même chose en coulisses (il compile ton code en bytecode `.pyc` avant de l'exécuter), mais cette étape est automatique et invisible — tu n'as jamais besoin d'y penser.*

## ⚙️ 3. Traduction en langage machine

Le compilateur ou l'interpréteur transforme les instructions en langage machine : une série de 0 et 1 que le processeur peut comprendre.

Exemple : l'instruction Python suivante

```python
print("Bonjour le monde!")
```

→ devient une série d'instructions comme :

```text
LOAD "Bonjour le monde!"
CALL print_function
```

→ puis en binaire (par octet, dans l'exemple suivant) :

```text
... 01001000 01100101 01101100 01101100 01101111 ...
```

## 🧩 4. Exécution par le processeur

Le processeur exécute ensuite les instructions binaires :

- Il lit les données en mémoire.
- Il effectue des opérations (calculs, affichage, etc.).
- Il interagit avec les périphériques (écran, clavier, disque dur…).

## 🖥️ 5. Affichage ou résultat

Une fois les instructions exécutées, tu vois un résultat à l'écran :

```text
Bonjour le monde!
```

## 🔄 Résumé du cycle

`Code source → [Interpréteur Python] → Langage machine → [Processeur] → Résultat`
